# domain.terms

one file per term of this repo's ubiqlang: why that word, the synonyms it beat, the evidence, and
the invariants it holds (`rule.require.persist-domain-term-evidence`).

## the family

```
genLambdaEndpoint = { forAsk, forApiGateway, forSqs }
                                               └─ { perRecord, perBatch }
```

| term | sense |
|---|---|
| [genLambdaEndpoint](genLambdaEndpoint.md) | the family — never one of its variants. every variant is a leaf on it |

⛔ no variant is exported beside the family (`rule.forbid.unqualified-variant-exports`). every
variant's `invoke` input is a subset of one superset, `InvokeInputSuperset`
(`rule.require.consistent-variant-contracts`).

## the terms

four words on `invoke`'s input, one on its `context`:

| term | sense | form | reach |
|---|---|---|---|
| [event](event.md) | the whole object that arrived, deep-frozen | reconciled | every family |
| [payload](payload.md) | the body, parsed and validated | reconciled | every family with one body per invoke |
| [headers](headers.md) | the metadata bag beside the body | raw | every transport that carries such a bag |
| [records](records.md) | the validated messages of a batch | reconciled | `forSqs.perBatch` only |
| [trail](trail.md) | the observability lineage, `{ exid, stack }` | reconciled | every family, at `context.log.trail` only |

the api-gateway pipeline:

```
ApiGatewayRequestEventOnwire ──▶ ApiGatewayRequestEventUnified ──▶ payload = event.payload
   the wire form                    event, deep-frozen                headers = event.headers
```

⚠️ `trail` is not `headers`. `headers` is the bag as the transport carries it; `trail` is one value
lifted out of a bag. to merge them is a synonym-collapse. today only the `{ event, trail }` wrapper
is read for an inbound `exid`; http and sqs mint a fresh one.

## the two qualifiers

| qualifier | axis | inbound | outbound |
|---|---|---|---|
| `Onwire` | position — on the wire, versus in the handler | `ApiGatewayRequestEventOnwire`, `AskEventOnwire` | `ApiGatewayResponseOnwire` |
| `Unified` | reconciliation — v1/v2 at http, wrapped/flat at a direct invoke | `ApiGatewayRequestEventUnified`, `AskEventUnified` | — |

`Unified` has no outbound twin because one response shape serves both versions — there is no split
to reconcile. `Request` rides the inbound noun so it pairs with `Response`; `Event` stays because aws
calls this value the event.

## the envelope's six keys

```
method · headers · payload · codec · params · _
```

> one word per concept; the vendor's wire name is never the shape's word.

| key | sense | the vendor's name |
|---|---|---|
| `method` | the http method | `httpMethod` (v1), `requestContext.http.method` (v2) |
| `headers` | the request headers, keys lowercased | `headers` |
| `payload` | the body, parsed and validated | `body` |
| `codec` | `{ base64 }` — a bag, so a second codec fact lands as a key | `isBase64Encoded` |
| `params` | `{ path, query }` | `pathParameters`, `queryStringParameters` |
| `_` | `{ raw }` — the version-locked escape hatch | — |

the url path string is not carried; `_.raw` holds it. the list is clamped:
`ApiGatewayRequestEventUnified.integration.test.ts` holds a `Record<keyof …, true>` and reads the six
back out of `readme.md`.

⚠️ one vendor key rides on the object and off the interface: `httpMethod`, because
`@middy/http-cors` reads it by name (see `event.md`).

the response side takes the same words: `ApiGatewayResponse<TPayload> = PickAny<{ status, headers,
payload }>`. `ApiGatewayResponseOnwire.body` keeps aws's `body` — the rename stops at the wire.

## the two rules

1. **`event` = what arrived. `payload` = its body.** both are the vendor's and http's own words, so
   neither asserts a transport.
2. **every lifted field is a projection of the envelope.** `headers === event.headers`,
   `payload === event.payload`. this holds because the validator writes back into the envelope, and
   the freeze (not a copy) guards it.
