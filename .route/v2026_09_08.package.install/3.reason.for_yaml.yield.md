# reason: yaml@2.9.0

## package
- name: yaml
- version: 2.9.0
- type: prod

## reason
runLambdaEndpoint.onSerialized at:local must resolve a handler from serverless.yml, which is how the incumbent invokeLambdaForTesting discovers a function locally (invokeLambdaForTestingLocally.ts:28-34). without it the 519 acceptance-test call sites cannot swap without each wiring its own resolver, which would break the wish done-when (a near one-line swap). pinned to 2.9.0 rather than the 2.8.2 already in the tree transitively: 2.8.2 fails the security audit (moderate, stack overflow via deeply nested collections).
