# 🌙 dream: reseed declastruct-aws with the sns, kinesis and sqs classes a delivery capture needs

kind: reseed · owner: ehmpathy/declastruct-aws · caught 2026-11-14

## .the cue that fired

sdk-aws-lambda's event-source schemas shipped on the aws docs samples (director verdict, F13 ruled
A). a captured real delivery would raise the grade, but the demo account cannot hold the infra as
code: `declastruct-aws` does not declare it.

## .the gap, precisely

measured, with controls:

- installed `1.5.2`: 35 classes (ec2, iam, lambda, log group, organization, rds, sso, vpc); no
  sns, kinesis or sqs class
- upstream `1.13.0`: `DeclaredAwsSnsTopic` only. `*Kinesis*` → 0, `*Mapping*` → 0,
  `*Permission*` → sso only. controls: `*Lambda*` → 8, `*Subscription*` → 1

## .the shape of the fix

add, as declared resources with idempotent get + set:

1. `DeclaredAwsSnsSubscription` — a topic → lambda subscription
2. `DeclaredAwsLambdaPermission` — the invoke grant an sns topic needs
3. `DeclaredAwsKinesisStream`
4. `DeclaredAwsLambdaEventSourceMapping` — kinesis (and sqs) → lambda
5. `DeclaredAwsSqsQueue`, if absent

then sdk-aws-lambda can provision the capture rig in `provision/aws.infra/account=demo/` and run
`dreams/2026_11_14.capture-real-sns-kinesis-deliveries.dream.md`.

## .why it is not done in this round

another repo's release; the director ruled the docs samples the sanctioned floor for this one.
