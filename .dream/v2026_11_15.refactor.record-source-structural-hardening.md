# 🌙 dream: harden the record-source family's structure, so the compiler and one suite carry what review carries today

- kind: refactor
- owner: sdk-aws-lambda
- caught 2026-11-15

## .the cue that fired

peer review of `feat-event-source-symmetry` (round i003, enroll-impl-arch-defects) raised four structural points. each is real, none ships harm, and each ripples past the diff that added the sns and kinesis families.

## .the gap, precisely

1. **the symmetry law is a jest clamp only.** a `RECORD_SOURCE_*` constant is not forced per source name, and the name list (`LambdaEventSchemaSourceName`) belongs to the schema face though the endpoint face now reads it too
2. **the shared leaves are clamped through sqs alone.** sns and kinesis tests never pass `logTranslate`, the redaction hook each of the five leaves wires by hand
3. **the two record builders repeat their tail.** each passes `source.carrier` twice (middleware and stamp); the per-batch builder holds three inline answer checks; the read and write halves of the `'headers' in record` fork are two units
4. **public-surface hygiene.** `RecordSuccessRef` lives in an orchestrator file and is named apart from `SqsRecordSuccessRef`; `EventDecodedOfSource` / `RecordDecodedOfSource` mash noun, state, and scope; `deserialize` is defaulted twice per call

5. **one `deserialize` default per source.** `asRecordBodyParsed` (endpoint face) and `asLambdaEventPayloadSchema` (schema face) each declare their own default, so a change to one splits the pair silently
6. **fifo order in the batch answer.** `getAllRecordIdsRetried` lists every unclaimed id; for a fifo sqs queue, aws asks for the first failure and every later message in its group. sqs shipped this before the diff; kinesis is safe, since it checkpoints at the lowest sequence number
7. **one wire shape, four descriptions.** the endpoint guard, the schema envelope, the `forAsk` id reader, and the `asLambdaEvent` builder each describe a source; `getIsSqsEvent` casts where the sns and kinesis guards use `Reflect.get`
8. **refusal line size.** the line carries the whole record, and a kinesis record reaches 1 MiB, above the cloudwatch event cap as best known (unverified here), which would break the replay claim
9. **the endpoint half meets no verbatim aws sample.** its tests build events with the package factories alone, so a factory drift passes both sides
10. **acceptance parity with sqs.** no acceptance cell for server-fault redrive at `forSns` / `forKinesis.perRecord`, an acknowledged handler `ConstraintError` at `forSns`, or the sns refusal line
11. **the strict-headers hint names api gateway** for every family (recorded `LIVE, NOT FIXED` in `setRecordValidated.ts`)

12. **a forwarded `ConstraintError` from a `perBatch` handler logs at debug only**, now for kinesis as well as sqs (`.dream/2026_10_22.sqs-forwarded-caller-fault-logs-loud.dream.md`); the record chain is one file now, so the shared-contract reason no longer holds
13. **each decoder repeats its payload step** (`deserialize ?? DEFAULT`, then parse or pass)
14. **a `trail` handed to `runLambdaEndpoint` for a `none` carrier is ignored silently**, where sqs honors it
15. **binary kinesis data meets a text hint**: gzip or kpl-aggregated data fails the json parse, and the hint points at `deserialize: { payload: false }`, which turns a loud refusal into silent mangled text
16. **more record-source cells lack an acceptance test or a whole-line snapshot**: count mismatch at `forSns` / `forKinesis.perRecord`, malformed answer and the wrong-shape refusal at `forKinesis.perBatch`, an all-refused and an unclaimable kinesis batch, a real sns refusal line
17. **`invariant.constraint-errors-never-redrive-sqs` names sqs alone**, though the shared leaves cite it for sns and kinesis

18. **the deserialize fix prints twice in one refusal line**: in the error header and again in the `hint` key beneath it. the same text is the extant `forSqs` contract, so a change reshapes a log line operators parse

items 5–11 were caught in round i004 of the same review, 12–17 in round i005, 18 in the 5.3 frictionless review.

## .the shape of the fix

1. `RECORD_SOURCES: Record<LambdaRecordSourceName, RecordSource>`, and `satisfies` ties from each family's keys to `for${Capitalize<Name>}` / `from${Capitalize<Name>}`, so a half-added source fails `tsc`. the jest clamp keeps only the one-sided list
2. one table-driven conformance suite over the five record leaves: `logTranslate` fires, a refusal warns and is acknowledged, a throw escapes, the batch-count refusal fires, the envelope is frozen, a fresh exid on `none`
3. `genRecordEndpointHandler({ logic, source, logTranslate })` for the shared tail; `assureRecordBatchAnswer` for the answer checks; `setRecordSlots` beside `asRecordSlots`
4. `RecordSuccessRef` to its own file; rename the two decoded types to `[...noun][state]`; make the decoders' `deserialize` required
5. one frozen default in `domain.objects/`, imported by both faces (with item 4)
6. an `ordered` fact on `RecordSource`, read by `getAllRecordIdsRetried`, once a fifo consumer needs it
7. derive the guards from the envelopes, once the envelopes accept every decoder fixture
8. measure the cap; then cap the logged record with `id` and the source arn always kept, or soften the replay claim
9. one verbatim aws-docs sample per source through its endpoint (in item 2's suite)
10. those three cells at `local.recordSources` (in item 2's suite)
11. a hint per family, from the source's own words, in the shared `getValidationError`
12. one log-and-rethrow `onError` entry in `genRecordEndpointMiddlewares`, clamped per batched source; amend the 2026-10-22 dream
13. `asRecordPayloadDecoded({ text, deserialize })` beside `asRecordBodyParsed` (with items 4 and 5)
14. a `ConstraintError` from the runner when `trail` meets a `none` carrier, until the sns and kinesis lifts land
15. the hint names binary data and `_.raw.kinesis.data` beside the opt-out
16. those cells at `local.recordSources` (with item 10)
17. widen the invariant to every record source, with the kinesis shard-hold and the `perBatch` throw exception
18. the header states the class and the paths; the fix lives in `hint` alone (in item 11's shared `getValidationError`, on a minor release)

## .why it is not done in this round

each touches the public type surface, every variant file, or both, so none is clean to ride along (`rule.always.fix-forward-under-scouts-honor`). a type rename on the public surface is a release decision too.
