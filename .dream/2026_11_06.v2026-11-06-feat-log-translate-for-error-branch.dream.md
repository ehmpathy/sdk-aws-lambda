# 🌙 dream: the io logger's error branch honors a redaction translate

kind: feat · owner: sdk-aws-lambda · caught 2026-11-06

## .the cue that fired

the vision for `fix-peer-failure-surfaces` raises `handler.output` on error from debug to warn/error. a service with `LOG_LEVEL=info`+ now emits a caller fault's raw message and stack for the first time.

## .the gap, precisely

`genIoLoggerMiddleware.onError` logs `request.error.message` + `.stack` raw (`genIoLoggerMiddleware.ts:66-70`). `logTranslate.output` applies only to the `request.response` branch, which is dead on the error path. `genInternalServiceErrorMiddleware` logs the same raw fields as `handler.error`. so `logTranslate` offers no redaction for any failure line.

## .the shape of the fix

add `logTranslate.error?: (error: Error) => Record<string, unknown>` and apply it at both failure lines (`handler.output` on error, `handler.error`). default = `{ errorMessage, stackTrace }`.

## .why it is not done in this round

the wish bounds the change to the log level. a new translate key is a public contract addition the wisher did not ask for, and the exposure it closes equals one that already ships for server faults.
