# 🌙 dream: clamp the fix-hint of `forApiGateway`'s wire-shape refusal

**kind** `fix` · **owner** `ehmpathy/sdk-aws-lambda` · **caught** 2026-09-25

## .the gap

`genLambdaEndpoint.forApiGateway.ts` refuses a handler that returns aws's wire shape:

```ts
if (keysOfResponseOnwire.length)
  MalfunctionError.throw(
    'handler returned the aws ApiGatewayResponseOnwire shape rather than an ApiGatewayResponse',
    { keysOfResponseOnwire, fix: 'rename `statusCode` to `status`, …', response },
  );
isApiGatewayResponse.assure(response);
```

the guard exists only to name the fix — the `assure` below rejects the same shape with *"does not
satisfy type.check"*. its message appears in 0 test assertions (control: the peer refusal *"neither
v1 nor v2"* → 2). delete the guard and `[case15]` stays green: it asserts only `statusCode === 500`.

## .the shape of the fix

```ts
then('the refusal names the rename, never a bare type-check failure', () => {
  expect(observed.message).toContain('ApiGatewayResponseOnwire');
  expect(observed.fix).toContain('rename `statusCode` to `status`');
  expect(observed.message).not.toContain('does not satisfy');
});
```

the 500 body is redacted by design, so `observed` must come from the log — the capture is the work.
bite: delete the guard; the new `then` goes red while `[case15]`'s extant assertions stay green.
