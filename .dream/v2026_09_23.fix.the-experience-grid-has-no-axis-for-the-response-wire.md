# 🌙 dream: the experience grid has no axis for the response wire

**kind** `fix` · **owner** `.behavior/v2026_09_20.feat-invoke-headers-event-payload/` · **caught** 2026-09-23

## .the gap

`1.vision.experience.dimensions.md` walks five axes (120 cells, 58 void) — all drawn around the
rename, a change to the **input** bag:

| axis | indexes |
|---|---|
| `A` | which input field the handler reads |
| `B` | author posture (new · in-repo · migrator) |
| `C` | wire version (v1 · v2) |
| `D` | feel (happy · sharp) |
| `E` | actor (author · consumer) |

so a handler's **return** and an author's **schema declaration** have no coordinate. rows 19–26 of
`1.vision.experience.case=_.md` sit marked `⛔ off the A–E grid`: `.strict()` outage, error metadata
on the wire, the introspection report, aws-native shape refused, explicit `''`, cors preflight
refused, `z.any()` opt-out, unexpected 500.

a grid that reads as complete beside 8 off-grid rows teaches the next reader to check five axes and
stop.

## .the shape of the fix

add an axis and re-walk:

```
F — the response the handler returns
  F1 json body · F2 status, no body (204) · F3 headers only (308 + Location)
  F4 verbatim non-json (xml) · F5 explicit '' · F6 aws-native shape (refused) · F7 sdk-authored error
```

decide first whether schema posture (`.strict()`, `z.any()`) is a seventh axis rather than a value
of `F`. then re-partition, recount voids, and re-verdict rows 19–26.

## .why it is not done here

safe (artifact edit), not clean: it reopens a partition three peer rounds settled, and a
verification stage must not redraw the vision's space without vision-grade review. the rows are
itemized and tested today.
