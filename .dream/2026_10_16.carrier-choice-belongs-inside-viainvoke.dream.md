# 🌙 dream: the carrier choice belongs inside `askLambdaEndpoint.viaInvoke`

kind: fix · owner: sdk-aws-lambda · caught 2026-10-16

## .the cue that fired

the level-3 peer review of #51 named the decomposition: `runLambdaEndpoint.onSerialized` and
`onReferenced` each ask `getOneTrailCarrierOfEvent`, branch on the answer, and build the carried
payload. the `viaInvoke` caller beneath holds the exid and the dialect, yet knows no carrier.

## .the gap, precisely

- `runLambdaEndpoint.onSerialized` (cloud branch) mints the exid, picks the carrier, builds the payload,
  pins `log.trail`, and then calls `askLambdaEndpoint`, which frames a wrapper or not by its own `struct`
- the choice lives in two callers, so a third caller (a new test util) would repeat it
- the headers carrier forces `struct: { payload: 'ancient' }` onto the inner call to stop a second frame

## .the shape of the fix

- `viaInvoke` takes a `carrier` (or reads the declared event itself) and owns: mint once, frame by
  carrier, send
- `onSerialized` drops its cloud branch to one call; `onReferenced` shares the same transformer
- clamp: `onSerialized.integration.test.ts` `[case21]` already pins the sent payload (header present,
  no wrapper, one exid), so the move is a refactor under a green clamp

the move needs no new public input: extract the tail of `viaInvoke` (endpoint resolution, sdk, cache,
execute) into an internal leaf that takes the framed payload and the exid, so `viaInvoke` becomes "frame as
wrapper, then invoke" and `onSerialized` at cloud becomes "frame by carrier, then invoke". that drops the
forced `struct: ancient`, the context re-pin, and the second `getOneTrailExid` call from the cloud branch.

## .why it is not done in this round

not clean: it reshapes the cloud road of a public operation that #51 does not name, and the cache key must
stay on the pre-carrier event so a per-call exid does not make every key unique. the clamp that makes the
move safe (`[case21]`) lands in this round.

## .the alternative on record

the event declaration rides a non-enumerable symbol that a copy loses (F5). a handler-side stamp
(the endpoint marks itself `forApiGateway` in `serverless.yml` or its builder) would survive a copy, at
the cost of a registry the runner reads. recorded in F5; rejected for now because the symbol keeps the
declaration where the event is built.
