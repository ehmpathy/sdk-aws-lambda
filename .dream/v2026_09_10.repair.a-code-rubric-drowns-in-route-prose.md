# 🌙 dream: a code rubric drowns in route prose, and fails in the direction nobody notices

- **kind** = reseed — the fix is in `rhachet-roles-bhrain`, never in this repo
- **owner** = `bhrain/role=driver` (the stone guard) + `bhrain/role=reviewer` (the review skill)
- **caught** 2026-09-10, at i018 r002 of `.behavior/v2026_09_03.feat-absorb-handler-invoke-test-util`

## .the cue that fired

`mech-failhides` returned `constraint ✋` rather than a verdict:

```
✋ prompt exceeds 75% of context window
   ├─ 75.2% of 1000000 tokens
   └─ reduce scope or use --focus pull
```

⇒ i went to scope it down, and the token breakdown said the scope was never the drive's fault.

## 🔴 .the gap, precisely — half a CODE rubric's prompt was PROSE

the stone guard hardcodes `--diffs since-main`. on a long drive that range is the whole route
directory, not merely the code. measured at i018, 143 files / 587.9k tokens:

| tree | tokens | share | can a `pitofsuccess.errors` rubric grade it? |
|---|---|---|---|
| `src/` | 263.3k | 44.6% | ✅ the subject |
| **`.behavior/`** | **252.9k** | **42.8%** | 🔴 route prose — `.given`/`.taken` trails, vision demos, fulcrums |
| `blackbox/` | 30.5k | 5.2% | ✅ the subject |
| `.dream/` | 27.6k | 4.7% | 🔴 no |
| `.agent/`, `readme.md`, `.route/` | 16.2k | 2.7% | 🔴 no |

⇒ **50.2% of the prompt is material the rubric cannot use**, and it is the half that grows on every
review round. a code rubric therefore gets *less* code in view the longer a drive runs — the exact
inverse of what a maturing diff needs.

## 🔴 .why it is worse than a mere waste

**it fails TERMINAL.** `constraint` and `malfunction` both unlock the next review level, so:

1. the reviewer grades naught
2. the guard reports it as resolved-for-unlock
3. the drive proceeds, and the level reads as reviewed

⇒ **an unrun reviewer is indistinguishable from a clean one**, which is the same shape
`bhrain/role=telepath`'s own readme names for context overflow. and it is silent for as long as it
lasts: `mech-failhides` last truly ran at **i008** and was blind through **i018** — ten iterations.

🔴 **the cost is not hypothetical.** that rubric caught the single sharpest defect of that drive: a
`.toBeUndefined;` with no parens — a property read that asserted naught and had survived nine prior
review rounds. **it is precisely the lens you least want to lose late in a drive**, because late
rounds add the most test code.

## .the shape of the fix

three candidates, cheapest first. any one closes it.

### 1. the rubric declares its own subject — preferred

a rubric knows what it grades. let it say so, beside its rules glob:

```
subject: src/**, blackbox/**          # or: paths-wout: .behavior/**, .dream/**, .agent/**
```

the guard then intersects `--diffs since-main` with that subject. **a prose rubric declares prose;
a code rubric declares code.** no per-drive tuning, and the scope shrinks as intended rather than
by accident.

### 2. the guard excludes the route directory by default

`--paths-wout '.behavior/**'` on every guard-driven review. cruder — it would wrongly narrow a
rubric whose subject genuinely IS the route artifacts (`behavior-intent-coverage` reads them) — so
it needs an opt-out, which is really candidate 1 with the default inverted.

### 3. an overflow is reported as a MALFUNCTION with a named remedy, never a bare constraint

whatever the scope fix, the failure mode should be loud. today the driver must notice a `constraint`
among nine `approved` rows and go read a log. it should say: *"this reviewer rendered no verdict.
re-run scoped, or the level is unreviewed."*

⇒ candidate 3 is worth having **even with** 1 or 2, because it is the guard against the next
unforeseen overflow.

## 🟡 .two obstacles in the manual workaround, which the fix should also address

the prescribed remedy (`rule.always.diagnose-reviewer-malfunctions`) is a scoped `rhx review`. it
works, and it cost four passes rather than one:

- **`--paths-with` takes exactly one glob.** repeated flags let the last win — silently, so the
  first scope vanishes with no warning. a comma-joined value resolves to **zero files** and fails
  loud. ⇒ either accept repeats as a union, or reject a repeat outright; the current quiet
  last-wins is the worst of the three.
- **the default brain was billing-suspended** (`412 Account vladatahbode is suspended`), so the
  scoped run needed an explicit `--brain anthropic/claude/code`. that is its own item — see the
  peer dream.
