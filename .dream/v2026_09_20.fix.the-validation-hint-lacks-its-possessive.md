# 🌙 dream: the validation hint lacks its possessive

> ✅ **CLOSED — REPAIRED, not deferred.** landed 2026-09-20 at stone `5.3.verification`, i005.
> the deferral below stood for three review rounds and rested on **an absence nobody had
> measured**. the repair took one `sedreplace` and one unit run.

- **kind** = fix
- **owner** = closed
- **caught** = 2026-09-20, at stone `5.3.verification`, peer review `r5.ergo-snapshot-visual-blemishes`, nitpick.1

## .the cue that fired

a reviewer read the hint as a caller meets it rather than as a diff, and heard the absent
possessive at once:

> *"the phrase 'the endpoint declared input schema' is missing the possessive — 'the endpoint's
> declared input schema' is grammatical."*

⇒ the tell is that **no author of the string heard it.** it was written, reviewed at three rounds,
and snapped into nine files before a reader who was told to grade *how it reads* met it.

## .the gap, precisely

```ts
// src/domain.operations/genLambdaEndpoint/middleware/getValidationError.ts
const VALIDATION_HINT_GENERIC =
  "send a value that satisfies the endpoint's declared input schema — correct each path named in `issues`";
//                                     ^^^^^^^^^^ was `endpoint`, wanted `endpoint's`
```

## .what was actually done

```
rhx sedreplace --old 'the endpoint declared input schema' \
               --new "the endpoint's declared input schema" --glob 'src/**'      --mode apply
rhx sedreplace --old 'the endpoint declared input schema' \
               --new "the endpoint's declared input schema" --glob 'blackbox/**' --mode apply
# the source literal switched ' -> " ; biome takes the delimiter that needs fewer escapes
rhx git.repo.test --what unit --mode apply --thorough        # <-- NO --resnap. that is the proof
```

result: **773 passed, 0 failed, 57 files.** green with no resnap means the hand-applied edit
equals what the code emits, byte for byte.

## 🔴 .why the three-round deferral was wrong

the deferral read: *"it ripples into FOUR acceptance snapshots and that gate cannot run here,
so the edit would leave four snapshots stale with no run to prove they moved correctly."*

every clause of that is true. **the conclusion did not follow**, and the reason is
`rule.require.positive-control-before-absence-claims`:

> *the costliest zero is the one that blocks a REPAIR, never the one that justifies a deletion.*

the claim behind the halt was **"no run available proves the transformation"** — an absence, and
nobody ran a control on it. a grep of the SUBJECT settles it in one command:

```
rhx grepsafe --pattern 'the endpoint declared input schema' --path . --glob '*.snap'
   -> 22 hits, 8 files, every one BYTE-IDENTICAL
```

| the 22 hits | count | can a run prove them? |
|---|---|---|
| acceptance snapshots — `local.sdkContract` ×8, `local.payloadCompat` ×3, `deployed.awsLambda` ×3, `local.wireResponse` ×1 | 15 | no — the gate |
| **unit snapshots** — `forApiGateway` ×1, `genZodBodyValidationMiddleware` ×2, `getValidatedInput` ×2, `forAskEndpoint` ×2 | **7** | **yes** |

and one of those seven is the control the deferral needed:
`genLambdaEndpoint.forApiGateway.test.ts.snap:22` carries the **fully-escaped JSON-in-string**
form — `\\"hint\\": \\"send a value…\\"` — which is the *identical shape* the acceptance `body`
and `text` hits have. so a unit run exercises both the plain form and the escaped form.

⇒ **the transformation was provable the whole time.** what could not run was the acceptance
suite; what needed proof was that one phrase swap reproduces the real emit — and that is a
unit-grain question.

## .the lesson, one level up

the deferral was not lazy. it was **thorough** — it named four files, cited the rule it failed,
attempted the edit, measured the ripple, reverted, and dreamed. every one of those acts made the
halt read more settled.

⇒ that is the shape to watch: **a well-argued deferral reads as a measured one.** the question
that dissolves it is never *"is my argument sound?"* but *"what did I RUN to establish the claim
I am blocked on, and did the same form ever return a hit?"*
