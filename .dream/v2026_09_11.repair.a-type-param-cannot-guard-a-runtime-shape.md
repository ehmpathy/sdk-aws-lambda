- **kind**: repair
- **owner**: `ehmpathy/sdk-aws-lambda`
- **caught**: 2026-09-11
- **fulcrum**: `F19` (the decision to defer lives there; this records the work)

## .the cue that fired

a scoped rerun of the `ergo-friction-hazards` rubric (its full-context run had overflowed since
i008) raised the ancient-envelope heuristic as a nitpick. the read that followed found a second half
the reviewer had not named.

## .the gap, precisely

`isLambdaEndpointErrorEnvelope<TDialect>` is a type guard whose dialect is a **type parameter**:

```ts
// isLambdaEndpointErrorEnvelope.ts:43-47
export const isLambdaEndpointErrorEnvelope = <
  TDialect extends LambdaEndpointDialect = 'contemp',
>(
  output: unknown,                                     // ← no dialect value. none.
): output is LambdaEndpointErrorEnvelope<TDialect> => {
```

`TDialect` is erased at runtime, so the check cannot consult it. Both branches run every time:

| step | line | what happens |
|---|---|---|
| 1 | `:62-63` | contemp — match the `_serde` tag. sound |
| 2 | `:66-70` | ancient — match the flat `{ errorMessage, errorType }` pair. a heuristic |

⇒ **checkable consequence.** a caller who writes `isLambdaEndpointErrorEnvelope<'contemp'>(out)`,
where `out` is a legitimate success shaped `{ errorMessage: string, errorType: string }`, gets `true`
— and `out` is then narrowed to a type shaped `{ error: { … } }` that it does not have. the next
`.error.message` read yields `undefined` against a type that promised a `string`.

**a guard handed out a type the value never satisfies.** that half is not a wire ambiguity; the
caller *declared* their dialect and the guard discarded the declaration.

## .the shape of the fix

three branches, and the cheap one already shipped:

| branch | move | state |
|---|---|---|
| **C** | name the ambiguity in `asLambdaEndpointOutput`'s hint, so a wrong diagnosis no longer sends an author after a rejection that never happened | ✅ **shipped 2026-09-11** |
| **A** | give the guard a runtime `dialect` argument, so `<'contemp'>` skips the ancient branch | deferred |
| **B** | read `TDialect` at runtime | ❌ impossible — erasure |

**branch A, concretely:**

1. `isLambdaEndpointErrorEnvelope(output, { dialect })` — the dialect becomes a value, beside the
   type parameter that shapes the return
2. `asLambdaEndpointOutput` and `asLambdaEndpointErrorEnvelope` forward it
3. every call site supplies it, or takes a `'contemp'` default that preserves today's behavior for
   the tagged path and changes it for the flat one

⚠️ **and the honest cost: A partially reverses F9**, which the wisher ruled — *"the payload dialect
travels in the return **type**"*. so this is a council question rather than a refactor.

## .why it is not done in this round

⇒ C landed at once. A is `safe 🔴 / clean 🔴`, which the rule's own table puts at *"defer — and raise

## 🟡 .the settler that would close this without A

> does any real handler return `{ errorMessage: string, errorType: string }` as a **success** output?

a measured `0` across the 20-repo / 318-site population reduces the misclassification half to a
theoretical risk, and C becomes the whole answer. the **erasure** half would still stand as an
unsound narrow, but with no reachable trigger.

⇒ the search is out of this repo's reach. it is named here rather than left implicit, because this
drive has already learned once (F14) that **a deferral which names a cheap settler and leaves it
unrun is an unasked question rather than a decision.**
