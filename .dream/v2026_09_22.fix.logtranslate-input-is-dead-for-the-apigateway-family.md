# 🌙 dream: `logTranslate.input` is dead for the api-gateway family — make it run, or refuse it loudly

**kind** `fix` · **owner** `ehmpathy/sdk-aws-lambda` · **caught** 2026-09-22 · fulcrum **F17**

## .the gap — LIVE, NOT FIXED

`genLambdaEndpoint.forApiGateway.ts` registers `genIoLoggerMiddleware({ logTranslate })` at index 3
and `genTrailMiddleware()` at index 8. `before` hooks run in forward array order, so the io-logger
reads `request.context.log` before trail writes it, finds `undefined`, and its `if (log)` guard
returns silently.

1. `logTranslate.input` never runs — a redaction projection is dead code
2. `handler.input` is never logged at all for this family

clamp: `genLambdaEndpoint.forApiGateway.test.ts` `[case16][t1]` asserts `translated.count === 0` —
green means the defect is present. `[case16][t0]` is the positive control on `forAsk`, whose
chain puts trail first.

## .the shape of the fix

**door 1 — make it run (preferred).** move `genTrailMiddleware()` above the io-logger. trail
declares only `before`, so the `after`/`onError` axis is untouched. but it would then sit above
`genApiGatewayEventNormalizationMiddleware` and read the raw v1/v2 wire union for its `exid`. probe
it: move, run `--what unit --thorough` and local acceptance, read what breaks.

**door 2 — refuse it loudly**, if door 1 fails: throw a `ConstraintError` at construction when
`logTranslate.input` is set on `forApiGateway`, with the hint *"redact inside `invoke`"*. count
`logTranslate` call sites across `ahbode/*` first — this turns a no-op into a load-time throw.

## .why it is not done here

not safe — door 1 changes what trail reads; door 2 throws for extant consumers. not clean — either
changes the chain for every `forApiGateway` handler, and the wish bounds this branch to `invoke`'s
input shape.

this is the `before` axis of one hook-order rule; the `onError` axis is
`v2026_09_22.fix.no-cors-or-owasp-headers-on-error-responses.md`, and the mechanism that would close
both is `v2026_09_22.fix.chain-order-is-prose-where-it-could-be-construction.md`.
