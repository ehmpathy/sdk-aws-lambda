# 🌙 dream: every 4xx/5xx ships with no cors and no owasp headers

**kind** `fix` · **owner** `ehmpathy/sdk-aws-lambda` · **caught** 2026-09-22 · **grade** urgent ·
fulcrum **F32 of `.behavior/v2026_08_03.feat-apigateway-wire-response`**

## .the gap — LIVE, NOT FIXED

a cross-origin browser caller cannot read any error body: a real 400/500 is indistinguishable from a
network failure.

middy runs `after` and `onError` in **reverse** array order, so an entry whose `onError` reads
`request.response` must sit at a lower index than the builders that set it:

| idx | entry | `onError` reads `request.response`? | verdict |
|---|---|---|---|
| 0 | `genContentTypeCoherenceMiddleware` | yes | ✅ runs last |
| 1 | `genConstraintErrorMiddleware` | sets it (400) | ✅ |
| 2 | `genInternalServiceErrorMiddleware` | sets it (500) | ✅ |
| 3 | `genIoLoggerMiddleware` | yes (truthiness guard) | ⛔ runs before the builders |
| 5 | `@middy/http-cors` | yes (`=== undefined` guard) | ⛔ no cors on any 4xx/5xx |
| 6 | `@middy/http-security-headers` | yes (`=== undefined` guard) | ⛔ no owasp on any 4xx/5xx |

membership is by cause, not guard syntax — a grep for the vendors' form misses entry 3.

clamps, green because the defect is present: `blackbox/local.httpResponse.acceptance.test.ts`
`[case8][t1]`, `[case11][t0]` (`⚠️ DEFECT: …` then-blocks that assert `toBeUndefined()`).

## .the shape of the fix

move `httpCors` and `httpSecurityHeaders` between entry 0 and entry 1, so their `onError` runs after
the builders. (the `before`-axis peer — trail above the io-logger — is
`v2026_09_22.fix.logtranslate-input-is-dead-for-the-apigateway-family.md`.)

prove it bites: reorder → the four `⚠️ DEFECT` clamps go red → then invert them to assert presence →
green. do not invert them first.

## .why it is not done here

not safe — the move also shifts the two vendors' `after` hooks relative to
`httpResponseSerializer`, which changes the headers of every success response. not clean — fresh
clamps on both paths for both vendors.

urgent by the closed set (behavioral: an allowlisted origin gets a 400 it cannot read and reports an
outage) — severity grades the harm, not the diff.
