# 🌙 dream: the middy chain's order invariant is prose, where it could be construction

**kind** `fix` · **owner** `ehmpathy/sdk-aws-lambda` · **caught** 2026-09-22 · **grade** better

## .the cue

peer review `r11:enroll-impl-arch-defects`: the order rule is enforced by a comment, the comment is
excellent, and it has still produced the same defect three times — each with its own dream, none
that names the cause.

| dream | the mis-placed entry |
|---|---|
| `…fix.no-cors-or-owasp-headers-on-error-responses` | two vendor entries, `onError` axis |
| `…fix.logtranslate-input-is-dead-for-the-apigateway-family` | `genIoLoggerMiddleware`, `before` axis |
| `ehmpathy/rhachet-roles-ehmpathy#657` (grepsafe last-wins `--path`) | the tool that hid the second axis |

fix all three and the fourth entry a future author adds is as unguarded as the first.

## .the gap

`genLambdaEndpoint.forApiGateway.ts` carries a `⚠️ THE INVARIANT` block with both axes —
`after`/`onError` run in reverse array order, `before` in forward order — above a plain array
literal. an author must infer which hooks their entry declares, what those hooks read, which entry
produces each value, and then pick an index by hand. a hook that reads an absent value silently
no-ops, so a mis-order yields a green suite and an absent header.

## .the shape of the fix

declarative placement: each entry states what it declares, reads, and produces; a builder sorts
them and refuses at gen time when a need cannot be met.

```ts
const entries = [
  { entry: genTrailMiddleware(), declares: ['before'], produces: ['context.log'] },
  { entry: genIoLoggerMiddleware({ … }), declares: ['before', 'after'], reads: ['context.log', 'response'] },
  { entry: genConstraintErrorMiddleware({ … }), declares: ['onError'], produces: ['response'] },
  …
];
export const chain = asMiddyChainOrdered({ entries }); // throws with the entry and its unmet need
```

the author never reasons about forward vs reverse; vendor entries get their reads stated on their
behalf, dist line cited; the failure moves from silent to gen time. the three instance dreams still
owe their own reorders.

## .why it is not done here

not safe — a sort computes a different order for at least three entries, which changes every
response's headers. not clean — a new operation, declarations for 11 entries, and an audit of five
vendor packages. the wish's bound forbids chain-order changes.
