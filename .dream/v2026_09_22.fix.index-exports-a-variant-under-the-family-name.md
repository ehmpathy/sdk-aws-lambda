# 🌙 dream: `src/index.ts` exports a variant under the family's name

**kind** `fix` · **owner** `ehmpathy/sdk-aws-lambda` · **caught** 2026-09-22 ·
🔴 **status: done** — landed on the branch that caught it (fulcrum **F15**)

## .the gap

`src/index.ts` exported `forApiGateway` bare (a preposition-led name that drops its file's variant
part) and `genLambdaEndpoint` from `genLambdaEndpoint.forAskEndpoint.ts` — a variant under the
family's name. the second caused the first: with the family name taken, the next peer had none to
qualify (`rule.forbid.unqualified-variant-exports`).

## .the fix, as shipped

```ts
export const genLambdaEndpoint = Object.assign(forAsk, {
  forAsk,
  forApiGateway,
  forSqs,
});
```

a **callable** family, ruled by the wisher, rather than the plain object this dream proposed — so
`genLambdaEndpoint({ … })` still resolves and `ahbode/svc-home-services` (4 call sites) is untouched.

## .the migration it costs

| consumer | edit |
|---|---|
| `ahbode/svc-gateway`, 78 files | `forApiGateway(` → `genLambdaEndpoint.forApiGateway(` |
| `ahbode/svc-home-services` | none |

mechanical and compiler-guided; it lands in the same release that already breaks `rawEvent`.
