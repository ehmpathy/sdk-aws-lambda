# 🌙 dream: replace the `⚠️` caution marker repo-wide

- kind: mechanic
- owner: sdk-aws-lambda
- caught 2026-11-15

## .the cue that fired

the adherence review of `asLambdaEventSchema.fromSqs.ts` hit `rule.forbid.width-ambiguous-glyphs`. `⚠️` (`U+26A0`) is `East_Asian_Width=Ambiguous`, so a terminal reserves one cell where an emoji font paints two.

## .the gap, precisely

`grepsafe '⚠️' --path src --path readme.md --path .agent/repo=.this/role=any/briefs` → 269 lines. the repo's comments and briefs use it as their caution marker.

## .the shape of the fix

- one pr: replace `⚠️` with `🟡`, the marker the rule names, across `src`, `readme.md`, and `.agent/repo=.this`
- skip cited foreign markers and verbatim quotes, per the rule's bound
- run the snapshot suites, since some stdout or prose snapshots may carry the glyph

## .why it is not done in this round

it touches about 269 lines in files outside this pr's subject. a swap of only the new files would leave two caution markers side by side in one repo.
