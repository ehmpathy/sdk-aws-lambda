# 🌙 dream: capture a real sns and kinesis delivery as a test fixture

kind: verification · owner: sdk-aws-lambda · caught 2026-11-14

## .the cue that fired

1.vision case=7 t4 names a captured delivery as the target grade of "real aws sample event"; the
docs samples are the floor. 5.1.execution shipped the floor only.

## .the gap, precisely

- `asLambdaEventSchema.{fromSns,fromKinesis}` are tested against the aws docs samples, verbatim
- the docs sns sample spells the cert url key with `URL`; `@types/aws-lambda` spells it with `Url`
  (F10). the schema makes both url keys optional, so either parses. only a real delivery says which
  key aws sends today
- `Subject: null` for a subject-less publish is asserted from aws behavior, not a capture

## .the shape of the fix

1. provision in the demo account (`provision/aws.infra/account=demo/`, `howto.provision-demo-infra`):
   an sns topic + a kinesis stream, each subscribed to an echo lambda that logs its event verbatim.
   no `declastruct-aws` release declares the set: installed `1.5.2` has no sns, kinesis or sqs
   class; upstream `1.13.0` adds `DeclaredAwsSnsTopic` but no subscription, lambda permission,
   kinesis stream, or event source link (controls: `*Lambda*` → 8, `*Subscription*` → 1). so this
   needs an upstream add to `declastruct-aws` (re-seed there) or a wisher-sanctioned one-off setup
   outside declastruct
2. publish one sns message with no subject, one with; put two kinesis records
3. commit each received event verbatim as a fixture beside the docs samples in
   `asLambdaEventSchema.test.ts`, with a case per fixture
4. settle F10: if aws sends the `Url` spelling, keep the key optional (docs drift) and say so

## .why it is not done in this round

the director ruled the docs samples the sanctioned floor for this release (F13, ruled A): a capture
needs aws credentials and infra the repo's declastruct provider cannot declare, and a delivery that
disagrees later loosens or tightens one schema, a clean rework. the path is the upstream add first:
`dreams/2026_11_14.reseed-declastruct-aws-sns-kinesis-sqs.dream.md`.
