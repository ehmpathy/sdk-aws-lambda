dream =

the sdk codegen should reconstruct domain-object REFERENCES, not just full-embedded
domain-objects. today a captured dobj travels whole (composition) — every field
inline. but a cross-service contract often wants to reference another dobj by its
key, not carry the whole thing. e.g. in the surfer-turtle world:

```ts
class SurfTrophy extends DomainEntity<SurfTrophy> {
  public static primary = ['uuid'] as const;
  public static schema = z.object({
    uuid: z.string(),
    rider: Seaturtle.refContract('primary'),  // → RefByPrimary<typeof Seaturtle>
    board: Surfboard.refContract('unique'),   // → RefByUnique<typeof Surfboard>
    sponsor: Sponsor.refContract('ref'),      // → Ref<typeof Sponsor>  (primary | unique)
    // ...
  });
}
```

and the generated svcSurf.resources.ts should emit:

```ts
import { DomainEntity, Ref, RefByPrimary, RefByUnique } from 'domain-objects';

export interface SvcSurfSurfTrophy {
  uuid: string;
  rider: RefByPrimary<typeof SvcSurfSeaturtle>;
  board: RefByUnique<typeof SvcSurfSurfboard>;
  sponsor: Ref<typeof SvcSurfSponsor>;
}
export class SvcSurfSurfTrophy extends DomainEntity<SvcSurfSurfTrophy> ... {
  public static primary = ['uuid'] as const;
}
```

## the "aha"

> "the trophy in my gateway doesn't copy the whole seaturtle rider — it references
> it by key, exactly as the upstream declared. and the reference is TYPED against the
> generated `SvcSurfSeaturtle`, so if the rider's primary key changes upstream, my
> next codegen shows the diff."

references, not just resources, cross the border with their identity intact.

## why this is the missing half

- `.contract` (shipped) embeds the WHOLE dobj → composition. good for "this field IS
  a surfboard".
- there is NO representation today for "this field REFERENCES a surfboard by key".
  `refByPrimary()` / `refByUnique()` are runtime instance ops that pluck key fields
  off a live object — they produce no schema, so no ref identity survives
  `z.toJSONSchema()`. a ref field currently goes over the wire as a plain anonymous
  shape (`{ uuid: string }`) with no hint it's a reference → the codegen emits an
  inline shape, and the reference relationship is lost entirely.

## the clean wire representation

a parallel pragma to `x-domain-object`, stamped by a future domain-objects
`X.refContract('primary'|'unique'|'ref')`:

```ts
// what refContract('primary') would stamp:
rider: z.object({ uuid: z.string() })
  .meta({ 'x-domain-object-ref': { name: 'Seaturtle', by: 'primary' } })
```

then the codegen:
1. reads `x-domain-object-ref` off a node → emits
   `Ref* / RefByUnique / RefByPrimary<typeof Svc<Prefix><Name>>` (by the `by` field)
2. adds the matching `domain-objects` import (`Ref` / `RefByPrimary` / `RefByUnique`)
3. requires the referenced dobj (`Seaturtle`) to ALSO be captured in full elsewhere in
   the service's contracts, so `typeof SvcSurfSeaturtle` binds — natural when a
   sibling endpoint returns the whole seaturtle. if it is NOT captured, fail loud
   (a new `LambdaDomainObjectRefUnbindableError`, exit 2, names the ref + hints to
   surface the referenced dobj on some endpoint).

## what it needs (two repos)

- **domain-objects** (dependency-wish): `X.refContract('primary'|'unique'|'ref')` that
  returns a zod schema of only the ref key fields, stamped with the
  `x-domain-object-ref` pragma. (handoff: $behavior/refs/handoff.domain-objects.ref.md)
- **sdk-aws-lambda** (this repo): read the ref pragma in the dobj-capture walk +
  emit the ref types + the domain-objects import + the bind-or-fail-loud check.

## demo (the acceptance proof)

extend the deployed surfer-turtle fixture with a `SurfTrophy` that exercises EACH of:
- `RefByPrimary<typeof X>`  (rider)
- `RefByUnique<typeof X>`   (board)
- `Ref<typeof X>`           (sponsor — primary | unique union)

and a sibling endpoint that returns each referenced dobj whole, so the refs bind.
snapshot the generated resources + assert each ref type + its import.

## until refContract lands

the fixture can hand-stamp `.meta({ 'x-domain-object-ref': { name, by } })` (mimicking
the future getter), so the codegen half can be built + tested without a block on
domain-objects. swap to the real `X.refContract(...)` once it ships.
