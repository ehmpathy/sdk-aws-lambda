## .the gap, precisely

`runLambdaEndpoint.onSerialized.ts` imports:

```ts
import { getParsedResponse } from '../askLambdaEndpoint/serde/getParsedResponse';
```

`getParsedResponse` is a **private serde leaf** of the `askLambdaEndpoint` operation — it is not on
that operation's public surface, and it is not exported from `src/index.ts`.

🔴 **the dependency carries real weight on a PUBLIC surface.** `onSerialized`'s local locus returns
whatever `getParsedResponse` returns, so a private refactor inside `askLambdaEndpoint` changes what a
consumer of the **published sdk** receives from a different operation.

⇒ the repo's own rule already prescribes the fix, and cites the trigger this case meets:
`rule.prefer.most-common-denominator` — *"2+ usages across sibling domains → proven need, lift
now."*

### the checkable evidence

| claim | how to check |
|---|---|
| it is a private leaf | `grep getParsedResponse src/index.ts` → no match |
| two operations use it | `askLambdaEndpoint/invoke/executeLambdaInvocation.ts` + `runLambdaEndpoint.onSerialized.ts` |
| it carries six local edges | `getParsedResponse.ts:1-13` |
| the peer half was lifted | `domain.objects/LambdaEndpointErrorResponseBody.ts` exists |

## .the shape of the fix

lift the wire serde to the common ancestor of both operations. the leaf cannot travel alone — it
sits atop six modules:

```
askLambdaEndpoint/error/getIsLambdaErrorResponse   (2 symbols)
askLambdaEndpoint/error/getLambdaErrorMetadata
askLambdaEndpoint/error/getStackTraceString
askLambdaEndpoint/serde/asUnprefixedErrorMessage
askLambdaEndpoint/serde/getDecodedPayload

```

⇒ so the move is the **subtree**, never the file:

```
src/domain.operations/askLambdaEndpoint/{serde,error}/  →  src/domain.operations/wire.serde/
```

then update the importers — `executeLambdaInvocation.ts`, `getLambdaErrorMetadata.ts`,
`onSerialized.ts`, `onReferenced.ts` — plus the test files and one snapshot
(`getParsedResponse.test.ts.snap`).

**every step is `tsc`-verified**, so the fix is mechanical rather than a redesign. one `tsc` run
after the move settles whether the 6-edge estimate was right.
