# case 3 — prod does not move

## narrative

a browser posts to `/notifications`. api gateway hands the lambda a raw v1 or v2 event, with no
`x-trail-exid`. normalization reconciles it, exactly as before. trail reads the reconciled headers,
finds no `x-trail-exid`, mints an exid, and flags the caller ancient. the browser receives the same
bytes it received yesterday — 200, 400, or 500.

the api gateway in front of it has x-ray on, so every request carries `x-amzn-trace-id`. no
matter: trail reads one key, its own.

## bdd

```
given('[case3] a raw aws api gateway event, v1 and v2, with no x-trail-exid')
  when('[t0] aws invokes the handler directly')
    then('a valid body: status 200, body and headers equal the extant [case1] snapshot')
    then('a refused body: status 400, errorType "BadRequestError", equal the extant [case2] snapshot')
    then('a handler throw: status 500, redacted body, equal the extant [case4] snapshot')
  when('[t1] the same event carries x-amzn-trace-id and traceparent')
    then('a refused body is still flat: errorType "BadRequestError"')
    then('context.log.trail.exid is minted fresh — neither generic header is read')
```

file may change; any diff is a stop, raised to the foreman.
