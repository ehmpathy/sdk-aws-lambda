# wish: an sdk-driven invoke of an api gateway endpoint reaches its handler, in the sdk's own default dialect

## .outcome

`ehmpathy/sdk-aws-lambda#51`: every `genLambdaEndpoint.forApiGateway` endpoint returns a redacted
500 when it is invoked through the sdk in its DEFAULT dialect (`struct.payload: 'contemp'`). the
handler never runs. fix it, so the default call works with no `struct` override at the call site.

## .why now

`declapract-typescript-ehmpathy` is about to release a practice (#650) that moves every service's
acceptance tests onto `runLambdaEndpoint`. until #51 is fixed, that practice must carry the
workaround `struct: { payload: 'ancient' }` at every api gateway call site, and every repo that
upgrades inherits it. a fix that ships first lets the practice drop the workaround before it
spreads to 100+ repos.

## .done when

- an api gateway endpoint invoked via `runLambdaEndpoint` (onReferenced and onSerialized) with
  `asLambdaEvent.fromApiGateway(...)` and NO `struct` reaches its handler and returns its result
- a test reproduces the redacted 500 under the current code, fails before the fix, and passes
  after it
- the raw event real api gateway delivers (`'ancient'`) still works, unchanged: production must
  not move
- every other endpoint family (direct, sqs, sns, kinesis, cloudfront) still passes
- released, and #51 closed by the release

## .context

- the issue body names the defect in full: the event normalization middleware runs BEFORE the
  trail middleware that unwraps the `{ event, trail }` frame, so normalization reads the frame,
  finds no http method, and throws `wire is neither v1 nor v2 api gateway event shaped`
- measured on `ahbode/svc-notifications`: 18 of 18 api gateway cases failed; every other family
  passed
- the issue lists candidate shapes for the fix; pick the one the evidence supports

- a release is a human gate. surface it with the exact command, never grant it yourself
