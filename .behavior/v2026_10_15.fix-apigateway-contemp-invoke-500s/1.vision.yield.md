# 1.vision — an sdk-driven invoke of an api gateway endpoint reaches its handler, in the default dialect

## .the outcome world

### day in the life

a service author writes an acceptance test for an http endpoint:

```ts
const res = await runLambdaEndpoint.onReferenced({
  handler,
  event: asLambdaEvent.fromApiGateway({ httpMethod: 'POST', path: '/notifications', body: { to } }),
});
expect(res.statusCode).toEqual(200);
```

no `struct`. it passes. the same call via `onSerialized({ at: 'local' })` passes. the handler ran,
and the response is the one the handler built.

the request the test sent is the request a peer service sends in prod: an api gateway event with
one more header, `x-trail-exid`. the peer sends it through the sdk's own api gateway caller.

### before / after

| | before (0.7.1) | after |
|---|---|---|
| default call | sends `{ event, trail }` → redacted 500, handler never runs | sends the event + `x-trail-exid` → handler runs, its response returns |
| `struct: { payload: 'ancient' }` | raw event, works | raw event, no header, byte-identical |
| real api gateway, no header (a browser) | works, ancient | works, ancient, byte-identical |
| a peer service over http | no way to opt in or pass a trail | `x-trail-exid` header → contemp + the peer's exid |
| caller exid on a contemp call | never reached the handler | `context.log.trail.exid`; a 500 `correlationId` names it |
| 400 body, no header | flat `{ errorMessage, errorType: 'BadRequestError' }` | unchanged |
| 400 body, header present | unreachable | nested `{ error: { _serde, class: 'ConstraintError', message } }` |
| a `{ event, trail }` wrapper at `forApiGateway` | 500 | 500, by declaration — and the log names the fix |

### the aha

aws owns the api gateway envelope, so no caller can wrap it. the opt-in and the trail ride the
envelope's own metadata bag — `headers` — the way http already carries such things. the test sends
what prod sends. `declapract-typescript-ehmpathy#650` drops `struct: { payload: 'ancient' }` before
it spreads to 100+ repos.

## .the cause, verified

`genLambdaEndpoint.forApiGateway.ts`, the `middlewares` array: index 7 = normalization (`before`),
index 8 = trail (`before`). middy runs `before` hooks in forward order. normalization reads the
contemp frame `{ event, trail }` (`serde/asFramedPayload.ts`), finds no http method, and
`asApiGatewayRequestEventUnified` throws `MalfunctionError: wire is neither v1 nor v2 api gateway
event shaped`. `genInternalServiceErrorMiddleware` redacts it to a bare 500.

the order is not the defect. the defect is the carrier: `runLambdaEndpoint` frames an api gateway
event the way it frames a direct invoke, and no aws-delivered event can arrive framed so.

## .the contract

the rules: `invariant.ancient-vs-contemp-callers.md`. the key: `domain.terms/x-trail-exid.md`.

1. **`forApiGateway` reads `x-trail-exid` from the reconciled headers.** trail stays after
   normalization — the current order, no swap. present (non-empty) → contemp, exid lifted into
   `context.log.trail`. absent → ancient, fresh exid. the `{ event, trail }` wrapper is no longer
   honored at this family; one opt-in per transport.
2. **a pure header builder.** `asTrailExidHeaders({ trail: { exid } })` → `{ 'x-trail-exid': exid }`.
   any http client spreads it in.
3. **the sdk's api gateway caller, `askLambdaEndpoint.viaApiGateway`.** its own inputs, the
   standard http request — `{ url, method, headers, body }`, as fetch takes them; no `which`. it
   merges (2) over the given `headers`, with the trail from `context.log`. a nested 400 comes back
   as a thrown `ConstraintError`, as `getParsedResponse` does for `askLambdaEndpoint` (F4, ruled).
   `askLambdaEndpoint` becomes a family per `rule.forbid.unqualified-variant-exports`: its bare
   name shipped, so `Object.assign(viaInvoke, { viaInvoke, viaApiGateway })` — extant calls unchanged.
4. **`runLambdaEndpoint` sets the header by default.** `struct: { payload: 'ancient' }` opts out: raw
   event, no header. it learns the event is http because `asLambdaEvent.fromApiGateway` declares
   it on its output — never a sniff of the event's shape (F5). every other event keeps the wrapper.
   absent a caller exid, it mints one, since the header carries a value or carries no opt-in.
5. **the answer follows the opt-in.** opted in → nested 400. not → flat. *"if someone calls with
   dialect contemp, return dialect contemp."* (F1)
6. **one-way families carry the trail only.** sqs, sns, kinesis have no reply, so no dialect. their
   lift is not built in this change (F3).
7. **cors allows the header.** a cors-configured `forApiGateway` endpoint lists `x-trail-exid` in
   `Access-Control-Allow-Headers`, so a browser preflight for it succeeds. the default today is
   `'content-type,authorization'` (`forApiGateway.ts:235`). an author who sets `cors.headers`
   still gets `x-trail-exid` appended, since the sdk expects the header everywhere (F6, ruled).

why not the swap: a swap makes the wrapper work at a family where aws can never send it. the test
would then pass on a request no prod caller can make.

## .mental model

"the sdk puts my trace id in a header, the way any http client would. if the header is there, the
endpoint knows i speak its modern dialect." analogy: a courier cannot open the post office's
envelope, so it writes the reference number on the outside, where the clerk reads it.

user terms: "default call", "struct", "header", "500". our terms: carrier, opt-in, trail, contemp.

## .evaluation

pros
- the test sends the exact request a prod peer sends; green proves a real path
- prod wire unchanged for every caller that sends no `x-trail-exid`, which is every caller today
- peers gain exid propagation across http, which no family had
- one rule per transport, stated in one invariant; no wrapper honored where aws owns the envelope

cons
- larger than a swap: a family-specific trail read, a builder, a caller, a default in
  `runLambdaEndpoint`, and a declaration on `fromApiGateway`
- a suite that drops `struct: { payload: 'ancient' }` rewrites its 400 assertions
  (`errorType` → `error.class`). by decree: no backcompat
- every cors-configured endpoint's preflight answer gains `x-trail-exid` — a visible header diff
  on `OPTIONS` responses (not on the ancient request path)
- the `logTranslate.input` defect stays live (trail still sits after the io logger). out of scope

edgecases
- a hand-built api gateway event, not from `fromApiGateway` → the wrapper → 500. the log names
  the fix: build it via `asLambdaEvent.fromApiGateway`, or set the header (case 5 `[t1]`)
- `x-trail-exid: ''` → treated as absent: ancient
- a real request that carries `x-amzn-trace-id` or `traceparent` → ancient; no generic header is read
- v1 passes header case through; normalization folds it lowercase before trail reads it

## .open questions & assumptions

- **[answered] F1** — contemp gets nested; the verdict carries to this design.
- **[best guess, clean] F2** — the key is `x-trail-exid`.
- **[answered] F3** — deferred. the wisher: decide first how a producer puts the exid on a message;
  the receive-side read follows.
- **[answered] F4** — `asTrailExidHeaders` + `askLambdaEndpoint.viaApiGateway`, both in this
  sdk; the caller takes `{ url, method, headers, body }` (the wisher's calls).
- **[best guess, clean] F5** — `fromApiGateway` declares http on its output; mechanism at blueprint.
- **[answered] cors** — the wisher: *"yes, it should - since we expect it"*. `forApiGateway`
  allows `x-trail-exid` in `Access-Control-Allow-Headers` (contract item 7).
- **[wisher, note only]** `struct.payload` reads as "request body" on http (`payload.md`). a
  `struct: { dialect }` rename is a separate decision; not folded in.
- **[wisher]** the release is a human gate: after merge, `rhx git.release --into prod --mode apply --watch`.
- assumption: no consumer depends on the 0.7.x contemp 500 (a defect, never a contract).

knock-on edits in execution: `rule.require.contemp-contracts-default.md:27` (absent opt-in =
ancient), `trail.md` (http lift moves to built), the `onReferenced` doc table (an api gateway event
receives the header, not the wrapper), the `forApiGateway` entry-1 note.

## .groundwork

### external research

- rfc 9110 §5.1 — http field names are case-insensitive; the fold makes one lowercase read correct
- sqs message attribute names are case-sensitive; one lowercase key survives both bags

### internal research

- `genLambdaEndpoint.forApiGateway.ts` — `middlewares` array, entries 7/8; entry-1 note
- `middleware/genTrailMiddleware.ts` — reads the wrapper only; writes `context.log`, `isContempCaller`
- `middleware/getUnwrappedEventWithExid.ts`, `frame/getIsWrappedPayload.ts` — wrapped iff exactly `{ event, trail }`
- `middleware/genConstraintErrorMiddleware.ts` — body chosen by `isContempCaller`, its one reader
- `runLambdaEndpoint/serde/asFramedPayload.ts` — contemp emits `{ event, trail: { exid } }`; the stack never crosses
- `asLambdaEvent/asLambdaEvent.fromApiGateway.ts` — returns a plain `APIGatewayProxyEvent`; `headers` + derived `multiValueHeaders`
- `lambdaEndpointWire/getParsedResponse.ts` — an api gateway response passes through untouched
- `__test_assets__/genApiGatewayProxyHarness.ts` — a local http harness; the home for case 7's test
- `ehmpathy/sdk-logs` `.behavior/v2026_04_28.trace-id/1.vision.md:281` — `x-trail-exid` precedent

## .what is awkward

- `genTrailMiddleware` is shared by every family; the header read is api-gateway-only. the family
  must hand trail its carrier, or own a trail read of its own — a blueprint choice
- `fromApiGateway` returns a plain aws type; a declaration on it must survive a json strip at
  `onSerialized`, or be read before the strip
- the header must land in `multiValueHeaders` too, or v1 fidelity breaks
