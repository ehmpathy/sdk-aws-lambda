# experience dimensions

the one canonical axes list for this vision. the yield and the inventory reference it; neither
restates it.

| axis | closed values |
|---|---|
| actor | test author · browser (no carrier) · peer service via the sdk's api gateway caller · peer lambda via `onSerialized(cloud)` |
| boundary | onReferenced · onSerialized(local) · onSerialized(cloud) · http via api gateway |
| carrier | `x-trail-exid` header (sdk default) · none (`struct ancient`, or a client that sends none) · `{ event, trail }` wrapper (foreign at this family) |
| event origin | `asLambdaEvent.fromApiGateway` · hand-built api gateway object · not api gateway · aws itself |
| outcome | success · caller fault (400) · server fault (500) · introspection |
| family | apiGateway · forAsk · one-way (sqs, sns, kinesis) · cloudfront |

## barred cells

| cell | kind | why |
|---|---|---|
| browser / peer service × onReferenced / onSerialized | impossible (nature) | a remote client reaches the lambda only via http |
| test author × http via api gateway | out of product (scope) | needs a deployed api; the local harness (`genApiGatewayProxyHarness`) stands in, under actor = peer service |
| http via api gateway × wrapper | impossible (nature) | aws builds the envelope; no client can wrap it |
| http via api gateway × origin ≠ aws | impossible (nature) | aws builds every event it delivers |
| onReferenced × cloud | impossible (nature) | a function reference cannot cross a process |
| sdk boundary × origin = fromApiGateway × wrapper | forbidden (invariant) | the builder declares http, so the default carrier is the header; a wrapper here is the 0.7.1 defect |
| sdk boundary × origin ∈ { hand-built, not api gateway } × header | out of product (scope) | the sdk never sniffs a shape; an undeclared event gets the wrapper (row 10) |
| family = forAsk × any | out of product (scope) | its carrier is the wrapper, unchanged; the extant suite is its proof |
| family = one-way / cloudfront × any | out of product (scope) | lifts recorded as next (F3); kinesis has no bag at all |
