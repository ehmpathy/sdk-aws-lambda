# case 1 — the default referenced call reaches the handler

## narrative

kai writes the first acceptance test for `sendNotification`. she copies the readme: hold the
handler, build the event with `asLambdaEvent.fromApiGateway`, call `onReferenced`. no `struct` —
the readme never mentions one. the test goes green: status 200, the body her handler built.

she logs `event.headers` in the handler once, out of curiosity, and sees `x-trail-exid` beside
`accept` and `host`. the sdk sent the request a peer service would send.

on 0.7.1 the same test went red with a bare `internal server error`, and no part of it named a
dialect.

## bdd

```
given('[case1] a forApiGateway endpoint')
  when('[t0] onReferenced runs it with a fromApiGateway event and no struct')
    then('the handler runs')
    then('status is 200 and the body is the handler's payload')
    then('the handler saw the event with an x-trail-exid header, never a { event, trail } wrapper')
    then('it is red on 0.7.1 — redacted 500')   // the clamp's teeth
```
