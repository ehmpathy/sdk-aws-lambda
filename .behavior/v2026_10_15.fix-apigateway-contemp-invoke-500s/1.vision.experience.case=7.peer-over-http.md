# case 7 — a peer service calls an http endpoint, opted in

## narrative

svc-orders needs svc-notifications to send a receipt, and svc-notifications exposes it only over
http. the svc-orders author calls it through the sdk's api gateway caller, with the trail she
already holds in `context.log`. the caller adds `x-trail-exid: exid:ord-7` to the request.

- the email is valid: 200, the handler's payload. svc-notifications' logs carry `exid:ord-7`, so one
  cloudwatch query shows both sides of the call
- the email is refused: the endpoint answers a nested 400. the caller casts it back into a thrown
  `ConstraintError` with the endpoint's message — the same shape `askLambdaEndpoint` throws. her
  catch block reads one class, whichever transport she used
- the endpoint is down: a 500, its `correlationId` = `exid:ord-7`. the caller throws a
  `MalfunctionError` that names it

an author on another http client (fetch, axios) spreads `asTrailExidHeaders({ trail })` into her
request and gets the same opt-in; she parses the nested 400 herself.

## bdd

```
given('[case7] a forApiGateway endpoint behind the local http harness (genApiGatewayProxyHarness)')
  when('[t0] askLambdaEndpoint.viaApiGateway({ url, method: "POST", headers, body }) sends a valid body, context.log.trail { exid: "exid:ord-7" }')
    then('the response is 200 with the handler's payload')
    then('the request on the wire carried x-trail-exid: exid:ord-7')
    then('the handler's context.log.trail.exid is "exid:ord-7"')
  when('[t1] the caller sends a body the schema refuses')
    then('it throws a ConstraintError whose message names the field — never returns a 400 to parse')
  when('[t2] the handler throws')
    then('it throws a MalfunctionError that carries correlationId "exid:ord-7"')
  when('[t3] fetch sends the same request with asTrailExidHeaders spread in')
    then('the 400 body is the nested envelope — the opt-in is the header, not the client')
```
