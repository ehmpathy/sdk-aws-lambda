# case 4 — a caller fault answers in the caller's dialect

## narrative

kai tests the refusal: an email the schema rejects. no `struct`, so the sdk sends `x-trail-exid`
and she is opted in. the call returns at once — the schema refused it before her `invoke` ran, so
no notification was sent and no partial work exists. the lambda succeeds (a caller fault is no
lambda error) and answers `{ statusCode: 400 }`. the body speaks the dialect she opted into:
`{ error: { _serde: 'LambdaEndpointError::contemp', class: 'ConstraintError', message: '...payload.email...' } }`
— the same envelope every other family hands a contemp caller, and the message names the field
to fix.

she wants one test that pins the browser's exact bytes, so she adds `struct: { payload: 'ancient' }`
to it. the sdk sends no header, and she gets the flat `{ errorMessage, errorType: 'BadRequestError' }`
that real browsers receive.

on either boundary the 400 is RETURNED, never thrown: it lives inside an http response, which no
envelope detector matches at its top level.

## bdd

```
given('[case4] a body the schema refuses: { email: "not-an-email" }')
  when('[t0] onReferenced runs it with no struct — x-trail-exid sent')
    then('fast: the handler's invoke never ran — no side effect, rejected at the boundary')
    then('loud: status is 400 and the invocation resolves — a returned answer, never swallowed')
    then('the body is the contemp envelope: error.class is "ConstraintError"')
    then('teaches the fix: error.message names "payload.email", the field to correct')
  when('[t1] onReferenced runs it with struct: { payload: "ancient" } — no header sent')
    then('status is 400 and the body is flat: errorType "BadRequestError", errorMessage names "payload.email"')
```
