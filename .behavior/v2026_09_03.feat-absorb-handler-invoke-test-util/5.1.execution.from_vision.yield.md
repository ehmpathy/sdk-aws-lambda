## .the three decisions the code makes that the vision left to the blueprint

### 1 — F9's "two knobs, one fact" is closed by DERIVATION, at rung 1

the vision named this as live design debt:

> *"the frame is driven by the author's `trail:` input; the dialect is declared by `struct.payload`.
> **two knobs, one fact**, so they can be set to disagree… the blueprint must pick; the vision does
> not."*

**picked: `struct.payload` is the sole declaration, and the frame follows from it.** `trail` supplies
only the exid. so `{ trail, struct: { payload: 'ancient' } }` cannot produce a contemp envelope under
an ancient return type — the disagreement is **unrepresentable** rather than policed
(`rule.prefer.prevent-over-correct`, rung 1, the same rung the barred cell uses).

### 2 — both serialized loci hydrate through ONE path

`at: 'local'` runs the handler in-process, then feeds the result through the **same**
`getParsedResponse` the wire path uses. so local and cloud cannot drift on what an envelope means —
which is the drift `#20` names, and the reason case=8's `[t1]` and `[t3]` both land on
`ConstraintError` whatever the dialect.

### 3 — the handler type is deliberately LOOSE

`LambdaEndpointHandlerReferenced<TEvent, TOutput>` does not demand a `genLambdaEndpoint` handler.
that is **F7**, and it is what makes the util an on-ramp: 19 of 20 repos still run
`createStandardHandler`, and they can swap the test import today with no handler migration at all.

## 🔴 .the defect the tests caught, which would have shipped broken

`getOneHandlerFromServerlessYml` opened with the reflex guard:

```ts
if (!(error instanceof Error)) throw error;   // 👎 the defect
```

**`instanceof` fails CROSS-REALM, and this code runs in the one place that has two realms.** jest
executes each module in its own vm context, so an `Error` its resolver constructs is not the test
realm's `Error`. the guard therefore rethrew the raw module error before the `Cannot find module`
check could run — and it would have done so **for every consumer**, since a test util is only ever
called from a test runner.

case=10's `[t0]` is the one test that crosses that boundary, and it is what failed. repaired by a
duck-type read of `.message`, with the reason left in the file so the next author does not restore
the reflex.

⇒ **the demo the vision wrote to prove error *quality* caught an error *correctness* defect.** the
case existed to check that a stale handler path blames the config; it found that the blame never
arrived at all.

## 🔴 .the defect a reviewer's ASIDE caught, which had shipped in every prior round

`getParsedResponse` is the one path §2 above leans on, and its fall-through was a failhide:

```ts
return parsed as TResponse;   // getParsedResponse.ts:116, before i026
```

**where aws reported a fault whose payload matched neither envelope shape, this operation handed the
fault to the caller as a SUCCESS** — `rule.forbid.failhide`, on a wire boundary, with aws's own
verdict (`functionError`) declared in the input type and never read in the body.

the check that ships only ever **NARROWS**, which is what let it land on sight rather than wait for
the F20 council:

| aws said | shape matched | before | now |
|---|---|---|---|
| fault | yes | throws, richly classified | **unchanged** — the shape branches win |
| fault | **no** | 🔴 **returned as a success** | throws, payload in `details` |
| no fault | — | unchanged | **unchanged** |

⇒ it converts no extant throw into a return, so it cannot commit the inverse failhide that F20's
branch A risks — which is the property that made branch A need a council in the first place.

⚠️ **and it does NOT fail open on the local locus.** `onSerialized.ts` passes
`functionError: undefined`, because there is no aws to ask, and `undefined` reads as *"no verdict —
trust the shapes"* rather than as *"no error"*. **aws is consulted where it spoke, never assumed
silent where it could not speak.**

⇒ clamped by four assertions (`[case8]` + `[case9]`), because the rule is a CONJUNCTION: a check
that fired on `functionError` alone would throw for every payload on the local locus, and three of
the four assertions would still pass. the inverted probe (`if (!input.functionError)`) kills the
suite at collection; the stubbed probe (`if (false)`) drops exactly `[case8][t0]`'s pair.

🔴 **and no reviewer charged it.** two l3 lanes converged on the unread parameter — one from the
signature, one from the F19/F20 pair — and the sentence that found the failhide was a
**parenthetical**, offered as context for an argument about the pair. ⇒ **a reviewer's asides carry
weight**, and a `.taken` that answers only the numbered blockers will walk past them.
