# case=3 — opt in to the old pass-through

feel: happy · care: critipath · boundaries: consumer call site → ask road → peer → hydration

## .narrative

svc-quotes proxies a validation endpoint. it forwards the browser's payload to svc-rates verbatim, so a refusal from svc-rates really is the browser's fault. its author wants the old 400.

she declares it at the call:

```ts
await askLambdaEndpoint(
  { which, event, refusal: { as: 'ConstraintError' } },
  context,
);
```

a peer refusal now throws `ConstraintError`, exactly as today. absent `refusal`, the default is `{ as: 'LambdaEndpointRefusedError' }`. the choice sits at the call site, where the author knows whose request it is.

the same input exists on `askLambdaEndpoint.viaApiGateway`, so one vocabulary covers both roads.

## .bdd sketch

```
given('a consumer that asks a peer which refuses')
  when('[t0] refusal is absent')
    then('throws LambdaEndpointRefusedError')
  when('[t1] refusal: { as: "ConstraintError" }')
    then('throws ConstraintError, with the peer message unprefixed, as today')
  when('[t2] refusal: { as: "LambdaEndpointRefusedError" }')
    then('throws LambdaEndpointRefusedError')
  when('[t3] the peer fails with a server fault, either opt')
    then('throws LambdaEndpointError, unchanged')
```
