# 1.vision.experience.case=_ — the inventory

one row per experience. rows 1-5 are the demos, and row N links `case=N` — one number, one sense. rows 6+ are itemized, forbidden, or impossible. each row names its cells in `1.vision.experience.dimensions.md`, so a reader maps a row to the product and back. ranked within each group by boundary-density.
