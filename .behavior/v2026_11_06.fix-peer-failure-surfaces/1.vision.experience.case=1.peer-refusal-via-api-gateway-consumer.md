# case=1 — a peer refusal, through an api-gateway consumer

feel: sharp · care: critipath · boundaries: http caller → consumer chain → peer lambda → hydration → consumer logs (the densest walk in the inventory)

## .narrative

svc-gateway serves `POST /notify`. it composes a request and asks svc-notifications via `askLambdaEndpoint`. svc-notifications rejects it: `ConstraintError: template id absent`.

today, svc-gateway rehydrates that as its own `ConstraintError`. its api-gateway chain answers 400 with the peer's message. the browser cannot fix it. cloudwatch Errors read 0. the only log line is `handler.output` at debug. on-call sees naught.

with the wish: the consumer throws `LambdaEndpointRefusedError`. its message names the cause, then the fix: *"svc-notifications refused the request: template id absent. this caller composed it; if it is your own caller's input forwarded verbatim, opt in with `refusal: { as: 'ConstraintError' }`"*. its metadata holds the peer's endpoint, exid, class, and details. it is not a constraint error, so the consumer's chain treats it as a server fault. the browser gets 500 with a correlationId and no peer detail. `handler.error` and `handler.output` land at error, with svc-gateway's function name and that message. on-call's alarm fires on the first one, and the line names both the cause and the one-key fix if the call is a true forward.

an older peer that answers the ancient shape (`errorType: 'BadRequestError'`) takes the same path: same class, same 500, same lines.

## .bdd sketch

```
given('an api-gateway consumer whose peer refuses the composed request')
  when('[t0] the http caller posts')
    then('the consumer answers 500, with a correlationId')
    then('the body holds no peer message')
    then('a handler.error line at error names the peer refusal')
    then('a handler.output line at error holds the same')
  when('[t1] the consumer catches by class')
    then('error instanceof LambdaEndpointRefusedError')
    then('error instanceof MalfunctionError')
    then('getIsConstraintError({ error }) === false')
    then('error.metadata names endpoint, exid, errorType: ConstraintError, details')
    then('error.message names the peer cause, then refusal: { as: "ConstraintError" }')
  when('[t2] the peer answers the ancient shape, errorType BadRequestError')
    then('error instanceof LambdaEndpointRefusedError')
    then('error.metadata.errorType === "BadRequestError"')
    then('the consumer answers 500, as in [t0]')
```
