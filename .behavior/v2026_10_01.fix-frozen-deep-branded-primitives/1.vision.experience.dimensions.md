# 1.vision.experience.dimensions

## the dimensions

| # | dimension | values | orthogonal because |
|---|---|---|---|
| D1 | actor, grouped by what they touch | holds a frozen value: **handler author** · holds the type: **sdk maintainer**, **type importer** · holds the install: **consumer repo maintainer** | who acts. the group is a property of the actor, not a second axis, so it rides as a label here. D2–D5 apply to the "holds a frozen value" group; D8 applies to the other two |
| D2 | leaf kind at a frozen slot | plain primitive (`string` · `number` · `boolean` · `bigint` · `symbol` · bare `null` / `undefined`) · **branded primitive** · plain object · class instance (dobj) · builtin on the object arm (`Date` · `RegExp` · `Error` · `ArrayBuffer` · `DataView` · typed arrays · `WeakMap` / `WeakSet` · `Promise`) · `Map` / `Set` · prop-less function · function with own props | closed by the arms of `FrozenDeep` itself: a value takes the primitive arm, the function arm, the `Map` / `Set` arm (type-fns only), or the object arm — no other arm exists. the object arm splits by who wrote the shape: plain, a class, or a builtin. type-fns names the builtins that keep the object arm (`FrozenDeep.ts:27-30` @ v1.21.5). a kind does not fix its nullability (D3), where it sits (D4), nor what is done to it (D5) |
| D3 | nullability of the slot | required (`T`) · nullable (`T \| null`) · optional (`T \| undefined`) | a property of the slot, not the leaf: any leaf can be nullable or optional |
| D4 | position of the slot in the payload | a field of the payload itself · a field nested in an object · an item in an array | any kind can sit at any position; the container is independent of the leaf |
| D5 | act on the value | **read / forward** to a sink typed with the original shape · **call a read member** (a getter, or a method that leaves the value as is: `.slice`, `.getTime`, `.get`, `.clone`, a call of the function itself) · **call a mutator** (a method that changes the value: `.setFullYear`, `.set`, `.add`) · **write** into it (assign to one of its fields) | any act can be attempted on any kind; the compiler, not the actor, decides which succeed |
| D6 | step | after step 1 (local fix) · after step 2 (sourced from type-fns) | a release axis, independent of who acts or on what |
| D7 | family | `forAsk` · `forApiGateway` · `forSqs.perRecord` · `forSqs.perBatch` | a trigger axis, independent of the value's shape |
| D8 | act on the type or the install | holds the type: **edit an arm** of `FrozenDeep` (primitive · function · array · `Map` / `Set` · object) · **consume** it (import from the root, under the sdk's own or another `type-fns`) — holds the install: **upgrade** the sdk with the patch **dropped** or **left** | closed: a type is either changed or used, and a change lands on exactly one arm; an install is upgraded, and the extant patch is either removed or kept |

## the collapses — each with its proof

- **D7 collapses.** every family types its slots through one `FrozenDeep` and freezes through one
  `setEventFrozen` (`grepsafe FrozenDeep --path src` → 4 variant files import it from
  `../setEventFrozen`). no cell differs per family.
- **D3 collapses to "narrow, then the leaf's own verdict".** `FrozenDeep<T>` checks a naked `T`, so it
  distributes over `T | null` and `T | undefined`: `null` and `undefined` take the primitive arm, the
  other member takes its own. so a nullable or optional slot has the leaf's verdict once narrowed;
  before the narrow, every act but read / forward is refused by `strictNullChecks` (row 19), unchanged
  by either step. the clamp asserts a nullable brand (case=1 `[t3]`) and, at execution, an optional
  one too — a distribution argument is still an argument.
- **D4 collapses to one verdict per (D2, D5), and is clamped rather than argued.** the object arm and
  the array arm each recurse by `FrozenDeep<member>`, so a leaf's verdict at depth n equals its
  verdict at the payload's own fields. the defect proves it: the probe measured `TS2322` at all three
  positions alike. the clamp asserts all three (case=1 `[t0]`–`[t2]`). a write is classed by what it
  writes into, at every position alike: `payload.at = x` writes into the payload (a plain object,
  row 4); `payload.at.x = 1` writes into the primitive (row 17).
- **D6 is a regression axis.** step 2 must leave each cell's verdict as step 1 left it, except where
  type-fns' `FrozenDeep` differs from the local one — which is D8's "edit an arm" walk below.
