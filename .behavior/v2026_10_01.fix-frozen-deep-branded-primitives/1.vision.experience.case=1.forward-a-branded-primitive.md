# case=1 — forward a payload that holds a branded primitive

critipath · happy · actor = handler author · inventory rows 1, 2

## narrative

svc-chat's `getThreadsByParticipant` declares `lastMessageAt: IsoTimeStamp` in its payload schema
and hands the payload straight to its query:

```ts
export const handler = genLambdaEndpoint.forApiGateway({
  schema: { input: z.object({ payload: schemaOfQuery }), output: … },
  invoke: async ({ payload }) => ({ payload: await getThreadsByParticipant(payload, context) }),
});
```

on 0.7.0, `tsc` refuses the call: the frozen `lastMessageAt` became a readonly map of every
`String.prototype` method plus `_dglo`, which is not a `string`. the author patches the sdk.

on 0.7.1 the call compiles. `FrozenDeep<IsoTimeStamp>` is `IsoTimeStamp`. the patch drops.

the same holds wherever the stamp sits — one level in (`payload.page.lastMessageAt`), as an item of
a list (`payload.lastMessageAts`), or nullable (`lastMessageAt: IsoTimeStamp | null`, a thread with
no message yet). each of those has no route around the break but a cast, so each is asserted here.

## timeline

```
given('[case1] a payload schema with `lastMessageAt: IsoTimeStamp`')
  when('[t0] the handler forwards `payload.lastMessageAt` to a sink typed `IsoTimeStamp`')
    then('tsc accepts the hand-off')                       # red on 0.7.0, green on 0.7.1
    then('the value at run time is the same string')       # unchanged: the runtime never froze it
  when('[t1] the stamp sits one level in — `payload.page.lastMessageAt`')
    then('tsc accepts the hand-off')                       # red on 0.7.0 (probe)
  when('[t2] the stamps sit in a list — `payload.lastMessageAts: IsoTimeStamp[]`')
    then('tsc accepts an item handed to an `IsoTimeStamp` sink')   # red on 0.7.0 (probe)
  when('[t3] the stamp is nullable — `lastMessageAt: IsoTimeStamp | null`')
    then('tsc accepts the hand-off to an `IsoTimeStamp | null` sink')
```
