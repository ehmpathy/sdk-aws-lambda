# 1.vision.experience.case=_ — the inventory

every row is a cell of the walked product in `1.vision.experience.dimensions.md`. rows are ranked by
boundary-density, densest first; the row number is the rank.

⚠️ a payload is NOT only json. a schema's `.transform()` or a dobj's `X.contract()` puts live class
instances into it (`getValidatedInput.test.ts:109` → `new Surfboard(…)`; v0.6.0, #44). so D2 holds
every kind a transform can return.

care is `freq × cost`. a path whose break leaves the actor no workable route is a critipath, whether
or not the same fix covers it.
