# case=3 — the type importer's import does not change

critipath · happy · actor = type importer

## narrative

a consumer names the frozen shape in its own signatures:
`import type { FrozenDeep } from 'sdk-aws-lambda'`. after step 2 the sdk no longer declares the
type; it re-exports type-fns'. the consumer's line is byte-identical and still resolves. what it
resolves to is now the shared, maintained declaration — the same one the rest of the ehmpathy
tree can import from type-fns directly.

## timeline

```
given('[case3] a consumer that imports `FrozenDeep` from the sdk root')
  when('[t0] the sdk is upgraded past step 2')
    then('the import still resolves')
    then('`FrozenDeep<IsoTimeStamp>` is still `IsoTimeStamp`')
```

the importer never sees whether the sdk still declares its own `FrozenDeep`; that is checked at
execution (repo-wide grep at the step-2 commit), not here.
