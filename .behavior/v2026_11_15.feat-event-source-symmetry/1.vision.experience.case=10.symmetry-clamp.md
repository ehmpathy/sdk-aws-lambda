# case=10 — the symmetry clamp — sharp × criti

## .narrative

a maintainer adds `genLambdaEndpoint.forDynamoStream` and forgets the schema half. the suite goes red and names the source and the absent half. they either add `asLambdaEventSchema.fromDynamoStream`, or add the source to the one-sided list with an axis — a decision the reviewer sees in the diff.

## .timeline

```
given the source set read from both family key sets (forX → X, fromX → X)
  and the one-sided list { apiGateway: '<axis>', ask: '<axis>' }
when every source has both halves, or sits on the list
then the clamp passes
when a source has forX and no fromX, off the list
then the clamp fails: 'dynamoStream has genLambdaEndpoint.forDynamoStream and no asLambdaEventSchema.fromDynamoStream'
when a source on the list gains its absent half
then the clamp fails too: the list entry is stale, remove it
```

## .the fail-safe

a list entry carries its axis, and a stale entry goes red — so the list cannot quietly grow or rot.
