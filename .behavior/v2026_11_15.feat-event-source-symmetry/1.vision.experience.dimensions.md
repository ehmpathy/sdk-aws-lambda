# 1.vision.experience.dimensions

## .the dimensions

| axis | values | why orthogonal |
|---|---|---|
| actor | endpoint author · test author · source maintainer · on-call reader | the primary axis: who meets the behavior |
| source | sqs · sns · kinesis | the record-source set; apiGateway · ask · s3 sit outside it (one-sided list) |
| cardinality | per record · per batch | present only where the source batches (sqs, kinesis) |
| record verdict | valid · schema refusal · schema fault · handler caller fault · server fault · count ≠ 1 | closed: every verdict the inventory uses is here. a schema fault is a schema callback that throws aught but a refusal: a fault of ours, never the sender's. the caller-fault vs server-fault split holds per record; at per batch any throw names no record, so both redrive the batch |
| event origin | this source · another source (a misrouted trigger) | the wire guard reads the event before any record does, so a foreign event fails before the record verdict exists |
| handler conduct | reads what it was handed · writes to it | the envelope and records are frozen; a write fails at compile time and at run time |
| batch answer | well formed · malformed | scoped to `cardinality = per batch`; a per-record variant returns void, so it has no answer to malform |
| delivery attempt | first · redelivered after a prior failure | kinesis checkpoints at the lowest failed record, so a record may arrive twice |
| payload decode | json · text | `deserialize: { payload: false }` |
| payload decode × body | json body · text body on the json default · text body opted out | the middle cell is the footgun: a text body left on the default reaches the schema as a string |

## .the faces, derived — not an axis

each actor meets one face of the change, so face is a function of actor, never a second axis:

| actor | face |
|---|---|
| endpoint author | the endpoint half (`forX`) |
| test author | the schema half (`fromX`) |
| source maintainer | the law (the clamp) |
| on-call reader | the log (the refusal warn) |

the log face has no axis of its own because the on-call reader carries it.

## .the walked product

the product is pruned by structural facts, each a stated invariant:

- sns × per batch = **forbidden**: sns delivers one record per invoke; a one-leaf sub-family is a variant with an extra hop
- kinesis × headers = **impossible**: a kinesis record carries no metadata bag
- batch answer × per record = **impossible**: a per-record variant returns void
- redelivered × sns = **covered by the async retry**: a redelivered sns message meets the same verdict as its first delivery
- sqs × endpoint is extant (`forSqs`) and out of scope, save where the clamp reads it

what remains:

| actor | cells walked |
|---|---|
| endpoint author | sns × {valid, schema refusal, handler caller fault, server fault, count ≠ 1} · kinesis.perRecord × {valid, schema refusal, handler caller fault, server fault, count ≠ 1} · kinesis.perBatch × {all valid, mixed, server fault, malformed answer, empty batch, every record refused} · kinesis × redelivered · any × text decode |
| test author | sqs schema × {valid, bad body, text body} · sqs schema under `forAsk` × {one bad record} |
| source maintainer | clamp × {source with both halves, source with one half off-list, source on the one-sided list, stale list entry} |
| on-call reader | every refusal × its warn line (`sns.record.refused`, `kinesis.record.refused`, `lambda.event.refused` with sqs ids) · the trail seam |

every cell is verdicted in `1.vision.experience.case=_.md`.
