# case=2 — kinesis.perBatch · a malformed answer — sharp × criti

## .narrative

kai refactors and returns `{ successes: records.map((r) => r.id) }` — bare strings, not records. or a hand-built `{ id: 'x' }` the sdk never handed over. the sdk cannot read which records landed, so it guesses none: it throws, the invoke fails, and kinesis retries the whole batch. the error names the shape it wanted.

## .timeline

```
given forKinesis.perBatch whose invoke returns { successes: ['seq1', 'seq2'] }
when the handler runs on 2 valid records
then the invoke throws a MalfunctionError that names `successes` must hold the records it was handed
  and no batchItemFailures answer is returned, so kinesis retries the batch
given an invoke that returns { successes: [{ id: 'never-handed-over' }] }
then the same throw, with the foreign id named
```

## .the fail-safe

an answer the sdk cannot read redrives, never deletes — the same contract `forSqs.perBatch` keeps (`records.md`, `[case9]`, `[case11]`, `[case16]`).
