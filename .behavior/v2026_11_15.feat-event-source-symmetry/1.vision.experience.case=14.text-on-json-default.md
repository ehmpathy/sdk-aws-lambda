# case=14 — sns / kinesis · a text body left on the json default — sharp × criti

## .narrative

a team moves a log stream onto `forKinesis.perRecord`. its producer writes plain sentences, not json, and the author declares `payload: z.object(...)` out of habit. the first record arrives; the sdk base64-decodes it, the json parse fails, and the text reaches the schema as a string. the schema refuses it, and the refusal is a caller fault, so the record is acknowledged and the shard advances.

every record of that stream would go the same way. so the refusal line carries the fix in words: set `deserialize: { payload: false }` and declare a text payload schema. the on-call engineer reads one line, flips one flag, and the next record lands.

the same holds at `forSns` with a text topic.

## .timeline

```
given forKinesis.perRecord({ schema: { input: z.object({ payload: z.object({ clickId: z.string() }) }) }, invoke })
when one record arrives with data = base64('hello world')
  then invoke is not called
  and one warn `kinesis.record.refused` { id: sequenceNumber, class: 'ConstraintError' }
  and its message names the fix: set `deserialize: { payload: false }` and declare a text payload schema
  and the invoke succeeds, so kinesis advances past the record
given the same endpoint with deserialize: { payload: false } and payload: z.string()
when the same record arrives
  then invoke receives payload = 'hello world'
```

## .the fail-safe

the loss is loud: no record of a text source is dropped without a line that names its cure. a `z.string()` payload on the json default is the quiet half (a line that is also json, `42`, is refused with no hint); the readme names it, and dream item 11 holds its repair.
