# 1.vision — an api-gateway handler owns its own wire response

> a lambda behind `sdk-aws-lambda` returns its **exact wire response** — any status, any
> headers, any body (or none) — and the sdk passes it through.

**the answer: widen the one contract.** `forApiGateway`'s output type becomes
`PickAny<{ status, headers, body }>`. no peer export, no mode flag, no second chain. this
**breaks** the return type, which the wisher licensed — the library has no installed base.

**the root cause:** the sdk had the wrong type at its output point. `invoke` returned a *body*, so
the wire encode had to invent the rest, and it invented
`{ statusCode: 200, body: JSON.stringify(x) }` (`forApiGateway.ts:168-171`). a body cannot carry a
status, so 204, 308, and xml were inexpressible by construction.

the wisher then directed a second, larger piece of work on the same insight: **name the four
points, at the common ancestor**, and bind them structurally so the conflation cannot recur. that
lift serves no acceptance line and is the bigger half of the diff — flagged for scope judgment.

> **archaeology lives elsewhere.** the reversals, draft histories, and self-review commentary that
> produced this design are in `archive/1.vision.narrative.md`. the probes and greps that verify it
> are in `appendix/verification.md`. this yield states the outcome.

## the four points

```
       inputBefore  →  inputAfter  →  [ invoke ]  →  outputBefore  →  outputAfter
         the wire in     yours           yours          yours          the wire out
             └ translate ┘                                 └ translate ┘
                        ↑                                 ↑
                   schema.input                      schema.output
```

| point | is | type | schema |
|---|---|---|---|
| `inputBefore` | the wire in, v1 or v2, untouched | `ApiGatewayRequestPayload` | — |
| `inputAfter` | what `invoke({ event })` gets | `TInput` | **`schema.input`** |
| `outputBefore` | what `invoke` returns | `ApiGatewayResponse<TBody>` | **`schema.output`** |
| `outputAfter` | the wire out, body already a string | `ApiGatewayResponsePayload` | — |

**the extant sdk had no name for either wire shape** — which is why the inbound translate exposed
only a sliver (`deserialize.body`) and the outbound one was hardcoded. a value you cannot say is a
value no reviewer can question.

**both schemas sit on the handler's side of their translator.** that is where the domain type is
live and where a mistake is still recoverable: a bad inbound shape is refused before the handler
runs, a bad response before the encode turns it to bytes. a schema on `outputAfter` would report
`{ statusCode, body: string }` and teach codegen none of the domain contract.

⚠️ **this diverges from the wisher's literal instruction** (*"schema.output should describe the
outputAfter"*) only because `outputAfter` was re-bound under it. the instruction's substance —
**the envelope, never just the body** — is kept; `outputBefore` is that envelope now.

**one wrinkle:** `before`/`after` alternates which side is outer. `inputAfter` and `outputBefore`
are the handler-side pair; `inputBefore` and `outputAfter` are the wire-side pair. check each shape
against this diagram, never against a peer's position.

## the contract

```ts
import type { PickAny } from 'type-fns';

/** .what = the http response a handler puts on the wire */
export type ApiGatewayResponse<TBody> = PickAny<{
  status: number;                      // defaults to 200
  headers: Record<string, string>;
  body: TBody;
}>;

/** .what = the wire payload an api-gateway trigger delivers, either version */
export type ApiGatewayRequestPayload = APIGatewayProxyEvent | APIGatewayProxyEventV2;

/**
 * .what = the wire payload api gateway receives back; body is a string by now
 * .note = `body` is OPTIONAL where aws declares it required — a body-less response must
 *         reach the wire with the key absent, never as `''` (probe → appendix)
 */
export type ApiGatewayResponsePayload = Omit<APIGatewayProxyResult, 'body'> & {
  body?: string;
};
```

`PickAny` requires at least one key, so `{}` is a **compile error**. that matters: an empty return
reaches middy's `normalizeHttpResponse`, which does `statusCode ??= 500` — a silent 500. the type
closes it, so no field must be required to stay safe.

| return | wire |
|---|---|
| `{ body: x }` | 200 + json |
| `{ status: 204 }` | 204, empty body |
| `{ status: 308, headers: { Location } }` | 308 redirect |
| `{ headers: { 'Content-Type': 'text/xml' }, body: xml }` | 200 + xml verbatim |
| `{}` | ⛔ compile error |

```ts
export const forApiGateway = <TInput, TBody>(
  config: {
    schema: {
      input: ZodSchema<TInput>;                       // describes inputAfter
      output: ZodSchema<ApiGatewayResponse<TBody>>;   // describes outputBefore
    };
    invoke: (
      input: { event: TInput; payload: ApiGatewayRequestPayload },
      context: ContextLogTrail,
    ) => Promise<ApiGatewayResponse<TBody>>;
    translate?: Translate<{
      inputBefore: ApiGatewayRequestPayload;
      inputAfter: TInput;
      outputBefore: ApiGatewayResponse<TBody>;
      outputAfter: ApiGatewayResponsePayload;
    }>;
    cors?: CorsConfig;
  },
  context?: ContextAwsLambdaServer,
): middy.MiddyfiedHandler<
  ApiGatewayRequestPayload,   // the outer shapes carry the outer names
  ApiGatewayResponsePayload,
  Error,
  Context
>;
```

⚠️ **the outer type parameters must be the two `*Payload` names, never AWS's raw types.** the
extant signature said `APIGatewayProxyEvent` — **v1 only** — though the family accepts either
version, so it understated what the handler takes: a v2 caller was fine at run time and a compile
error for anyone who typed against the returned handler. verified by tsc, which rejected the union
against the old shape with `'APIGatewayProxyEventV2' is not assignable to
'APIGatewayProxyEventBase<...>'`.

### `schema` is required; `z.any()` is the opt-out

absence would fork **validation and introspection at once**, and a caller who forgot the field
would be indistinguishable from one who chose to skip it. required-with-a-visible-opt-out collapses
both branches (`rule.require.explicit-optout`).

it also makes introspection always available: an endpoint with `z.any()` honestly reports `any`.

the envelope costs ceremony, so the family ships the builder:

```ts
/**
 * .what = wraps a body schema into the response-envelope schema
 * .why = keeps the common case a one-liner, and keeps the body type reachable for codegen
 *
 * .note = `body` is NAMED because the envelope has three fields and the argument must say
 *         which one it supplies
 */
export const asApiGatewayResponseSchema = <TBody>(input: {
  body: ZodSchema<TBody>;
}): ZodSchema<ApiGatewayResponse<TBody>> => ...;
```

```ts
output: asApiGatewayResponseSchema({ body: MyBodySchema }),   // 200 + json
output: asApiGatewayResponseSchema({ body: z.undefined() }),  // no body
output: z.any(),                                              // opt out
```

per the wisher, the `z.undefined()` requirement is a **pro**: the contract states its own truth
about whether a body exists, so a reader, a reviewer, and the introspection report all learn it
from the declaration.

### serialization needs no fork

`httpResponseSerializer` skips when `Content-Type` is already set. so:

- **handler omits `Content-Type`** → serializer stringifies `body`, stamps `application/json`
- **handler sets it** → serializer returns early, body reaches the wire byte-identical

the escape hatch and the paved road are the same code path. under the old chain, xml was measurably
json-quoted **and** re-stamped `application/json` → twilio 11200 (`appendix/verification.md`).

## `translate` — the namespace, at the common ancestor

> **scope note:** the wish's `.acceptance` has no line about config namespaces. the wisher
> directed *"solve it generically, at the most common ancestor"*. the bound grew by instruction.

### the dimension already exists — four times, named none of them

| family | direction | the extant translate | exposed? |
|---|---|---|---|
| `forApiGateway` | in | v1/v2 unify + body parse | a sliver (`deserialize.body`) |
| `forApiGateway` | out | `{ statusCode: 200, body: JSON.stringify(x) }` | not at all |
| `genLambdaEndpoint` | in | `getUnwrappedEventWithExid` — strip the `{ event, trail }` wrapper | not at all |
| `genLambdaEndpoint` | out | `getValidatedOutput` passthrough — return IS the payload | n/a |

row 2 is the wish's own root defect: an outbound translate so thoroughly unnamed it was hardcoded
to one shape. `IoLogTranslate` is likewise declared inline in **both** families
(`forAskEndpoint.ts:58,90`; `forApiGateway.ts:69,132`) — one contract duplicated at two leaves
(`rule.prefer.most-common-denominator`).

### the shape

```ts
// genLambdaEndpoint/ — the common ancestor of both families

/** .what = projections applied to io before cloudwatch; cosmetic, never on the wire */
export interface TranslateLog {
  input?: (payload: unknown) => unknown;
  output?: (response: unknown) => unknown;
}

/**
 * .what = a function that re-renders one shape as another
 * .why = `translate` is extant vocabulary — `logTranslate`, `IoLogTranslate`,
 *        `translateInput`, `translateOutput` (genIoLoggerMiddleware.ts:3,17,23-25);
 *        `-or` is the sanctioned agent suffix
 */
export type Translator<TFrom, TInto> = (from: TFrom) => TInto;

/**
 * .what = the four shapes an endpoint's data takes, named at the translator boundaries
 * .why = these are the fundamental types of any lambda endpoint, and the pairs most often
 *        conflated. a named bag is a STRUCTURAL BIND — the compiler holds the vocabulary
 *
 * .note = a SHAPE is not a TRANSLATE SLOT. all four shapes exist on every endpoint;
 *         `Translate` offers a slot per boundary a consumer may drive. do not delete a
 *         shape because its translate has a fixed default — that erases the vocabulary
 *         the bind exists to hold
 */
export interface LambdaEndpointShapes {
  inputBefore: unknown;
  inputAfter: unknown;
  outputBefore: unknown;
  outputAfter: unknown;
}

/**
 * .what = what changes en route, and what logs see
 *
 * .note = each payload member is TRI-STATE:
 *
 *   absent   -> the family's default translator runs
 *   false    -> DISARMED; no translate, the shape passes through untouched
 *   function -> yours, in place of the default
 *
 *         on `output`, DISARMED means the handler returns the wire shape itself.
 *
 *         the off-state is `false`, never `null`. absent and off carry OPPOSITE senses
 *         here, so they must not be the two most confusable values in the language
 *         (rule.forbid.opposite-senses-on-undefined-and-null). `false` also matches the
 *         extant grain: this repo reads `null` as an absent value and `false` as a switch
 *         that is off — and this concept already shipped as `deserialize: { body: false }`
 */
export interface Translate<TShapes extends LambdaEndpointShapes> {
  payload?: {
    input?: Translator<TShapes['inputBefore'], TShapes['inputAfter']> | false;
    output?: Translator<TShapes['outputBefore'], TShapes['outputAfter']> | false;
  };
  log?: TranslateLog;
}
```

### the noun is `payload`, and it is bidirectional

verified: `payload` names the wire-side representation in **either** direction
(`sdkLambdaInvoke.ts:10,39` use it for a response), while `event` is inbound-only and
post-translate. so the translate reads **payload → event** inbound and **response → payload**
outbound.

`response` is likewise this repo's term for the value that goes back (402 occurrences in `src/`).
`ApiGatewayResponsePayload` therefore reads as *the wire form of the response* — `Payload`
**qualifies** `Response`, so it is the `IsoPriceWords` case rather than a mash, and it sorts under
`ApiGatewayResponse*` so autocomplete shows a reader the handler shape and its wire form together.

**and the wire pair is `request`/`response`, never `event`/`response`** (F29). `Payload` qualifies
both ends identically, so the two wire shapes are a matched pair rather than two unrelated names:

| | handler-side | wire-side |
|---|---|---|
| **in** | `TInput`, via `asApiGatewayEvent` | `ApiGatewayRequestPayload` |
| **out** | `ApiGatewayResponse<TBody>` | `ApiGatewayResponsePayload` |

`event` is what the **handler** calls its input, so it belongs in the left column and in the
transformer that targets it (`rule.prefer.symmetric-term-pairs`).

⚠️ **one consequence worth a reviewer's note.** `UnifiedApiGatewayEvent` (14 occurrences, 5 files,
exported at `src/index.ts`) carries its `Unified` qualifier only because AWS's
`APIGatewayProxyEvent` held the plain name. with the raw shape now called
`ApiGatewayRequestPayload`, the plain `ApiGatewayEvent` is free — so `Unified` may be droppable.
**not acted on here:** `Unified` does name a real concept (the v1/v2-normalized envelope), and the
rename touches 5 files for no acceptance line.

### both defaults are exported `as*` transformers

each names its **target**, per `as$Noun`, and each takes `(input, options)` per
`rule.require.input-options-pattern` — `deserialize` is pure config, not a dependency:

```ts
/**
 * .what = the api-gateway payload translator: v1/v2 unify + base64 decode, then body extract
 * .note = it composes BOTH extant input steps, so its output is what invoke gets (inputAfter).
 *         the intermediate UnifiedApiGatewayEvent is a step INSIDE it, never a model point
 */
export const asApiGatewayEvent = <TInput>(
  input: { payload: ApiGatewayRequestPayload },
  options?: { deserialize: { body: boolean } },
): TInput => ...;

/** .what = the wire encode: status ?? 200, body ?? '', body -> string */
export const asApiGatewayResponsePayload = <TBody>(
  input: { response: ApiGatewayResponse<TBody> },
): ApiGatewayResponsePayload => ...;
```

| slot | default | `false` means |
|---|---|---|
| `payload.input` | `asApiGatewayEvent`, `deserialize.body: true` | the untouched wire event reaches `invoke` |
| `payload.output` | `asApiGatewayResponsePayload` | `invoke` returns the wire result itself, verbatim |

that `false` on the output side is **total wire control** — what the hand-rolled
`forApiGatewayPlain` adapter did (`0.wish.md:53-73`), now declarative.

`asApiGatewayEvent` returns `TInput`, **not** the intermediate envelope. that kills the extant
`event.body as TInput` cast (`forApiGateway.ts:158`) — an `as`-cast that asserted the relation the
translator should derive (`rule.forbid.as-cast`).

### the slots compose

```ts
// unify, no body parse — exactly today's `deserialize: { body: false }`
input: (payload) => asApiGatewayEvent({ payload }, { deserialize: { body: false } }),

// disarmed — the untouched APIGatewayProxyEvent reaches invoke
input: false,

// redact every response, then encode
output: (response) => asApiGatewayResponsePayload({ response: asRedactedResponse(response) }),

// hand invoke a domain object
input: (payload) => asSurfLesson(payload.Records[0].body),
```

**`deserialize` is removed from endpoint config** (the wisher's call) and survives as the
translator's option — no capability lost, the option now sits on what it configures.

### `payload.output`'s evidenced consumers

| consumer | supplies |
|---|---|
| the wire encode | the family's default |
| a redaction pass | strips PII / secrets from **any** response before it leaves |
| a profanity flag | screens generated body content |
| total wire control | `false` — `invoke` emits the `ApiGatewayResponsePayload` itself |

redaction and profanity are consequential: they change what the http client receives, so neither
can live in `translate.log` (cloudwatch-only) and neither belongs in the handler, since the point of
a redaction pass is that **every** response gets it whatever branch produced it.

**a reviewer's test:** a slot earns its place if a **consumer** can name a transform they would put
in it. do not test the slot against the sdk's own defaults — the sdk's default is only ever the
first occupant.

### the tri-state collapses once, at construction

no code path may fork on which state the caller supplied (`rule.forbid.parallel-codepaths`):

```ts
const translateIn =
  config.translate?.payload?.input === false
    ? identity
    : (config.translate?.payload?.input ??
       ((payload) => asApiGatewayEvent({ payload }, { deserialize: { body: true } })));

const translateOut =
  config.translate?.payload?.output === false
    ? identity
    : (config.translate?.payload?.output ??
       ((response) => asApiGatewayResponsePayload({ response })));
```

three states in, one function out per side. this is the **one** place the off-state and `undefined`
must be told apart, which is why the `.note` declares the distinction rather than leave it to
inference (`rule.forbid.undefined-inputs` — the declared exception). the `=== false` guard is also
why the off-state must not be `null`: `if (!supplied)` would collapse absent into off, and
`?? default` would treat off as absent.

**the off-state needs no equality constraint.** `false` makes `inputAfter ≡ inputBefore` by
construction, and a mismatched `schema.input` fails loud at validation anyway
(`rule.avoid.constraints-the-state-already-proves`).

### the boundary — what belongs under `translate`

**a translate re-renders the same subject, derived from that subject.** lossiness does not
disqualify — a summary and a redaction are both translations. **fabrication** and **substitution**
do.

| operation | translate? |
|---|---|
| deserialize body, v1/v2 unify, trail unwrap | ✅ same subject, re-rendered |
| the wire encode, a response redaction, a log projection | ✅ same subject, lossy |
| schema validation | ⛔ asserts about it, re-renders no value |
| cors / security headers | ⛔ **fabricates** info absent from the subject |
| error → response, introspection short-circuit | ⛔ **substitutes** a different subject |

so `cors` and `schema` stay **peers** of `translate`, never members. apply this test to any future
config member.

### the trail unwrap is an invariant, never replaceable

`getUnwrappedEventWithExid` yields **three** values (`getUnwrappedEventWithExid.ts:13-17`):
`unwrappedEvent`, `exidFromPayload`, `isContempCaller`. trail correlation and the
ancient-vs-contemp error contract both ride on it. it **reads** and re-renders no value, so it is
no translate — it runs first, outside the namespace, and all four points sit after it.

### one coupled note

`schema.input` describes the **post**-translate shape, so a consumer who supplies a custom
`payload.input` owes a `schema.input` that matches that translator's output. `schema.output` owes no
such debt — it sits **before** its translator, so it always describes exactly what `invoke` returns.

## before / after

| dimension | before (hand-rolled adapter) | after (widened) |
|---|---|---|
| 204 / 308 / xml | only if you leave the sdk | first-class |
| error contract | re-typed per repo, drifts | the sdk's own seam, one definition |
| trail (`exid`) | lost | kept |
| io logs | lost | kept, metadata-only by default |
| introspection | lost | kept — always, since schema is required |
| v1/v2 normalization | dropped deliberately | opt-out-able — `input: false` |
| payload transform, both ways | hardcoded | declared, overridable |
| lines a consumer writes | ~20 + its tests | 0 |
| sdk exports involved | n/a | **one** — `forApiGateway` |

the normalization row is not a tradeoff: `input: false` hands `invoke` the untouched v1-or-v2
event, exactly what the hand-roll received. the default gives normalization; an opt-out by value at
the call site gives the raw event. no power lost either way.

### the wish's own open question, answered

> *"does the passthrough own the SUCCESS path only, or the error path too?"* — `0.wish.md:103`

**the success path only; the platform keeps errors — as a fallback, never a cap.** a handler that
wants to own an error response catches and returns one:

```ts
invoke: async ({ event }) => {
  try { return { body: await renderTwiml(event) }; }
  catch { return { status: 422, headers: { 'Content-Type': 'text/xml' }, body: errorTwiml }; }
}
```

so neither choice is exclusive, which defuses the reversibility worry: full error ownership is
available today with no sdk change.

### timeline (bdd)

```
given  a twilio number pointed at an api-gateway route backed by forApiGateway
when   twilio POSTs a form-encoded voice webhook
then   the handler runs with a fresh trail exid and the raw body string

```

`genConstraintErrorMiddleware.ts:11` already declares `ApiGatewayResponse` as

the extant one is a hand-copy of `APIGatewayProxyResult`, so **delete it** and use

## mental model

> "you hand the sdk a response instead of a value. omit `status` and it is a 200; omit `body` and
> there is no body; set a `Content-Type` and your bytes are yours."

| they say | we say |
|---|---|
| "raw / passthrough response" | `ApiGatewayResponse` |
| "no schema" | `z.any()` — an explicit opt-out |
| "no body" | `body` omitted |
| "the raw event" / "the parsed event" | `inputBefore` / `inputAfter` |
| "what my handler returns" | `outputBefore` |
| "what goes on the wire" | `outputAfter` |
| "the response schema" | `asApiGatewayResponseSchema({ body })` |
| "sanitize every response" | `translate.payload.output`, wrapped over the default |
| "i want to emit the raw wire result myself" | `translate.payload.output: false` |

there is deliberately **no new noun** for a response mode. `forApiGatewayWire` mashed trigger with
response mode as if "ApiGatewayWire" were a platform (`rule.forbid.names-that-mash-dimensions`).

## evaluation

| acceptance line | met by |
|---|---|
| arbitrary status / headers / body, empty one too | `PickAny<{ status, headers, body }>` returned unmodified |
| 204 / 308 / xml each proven expressible | three wire-byte tests |
| `BadRequestError` → 400 w/ errorMessage/errorType/causeMessage | reuse `genConstraintErrorMiddleware({ apiGateway: true })` — already emits exactly this |
| that 400 leaves the invocation a SUCCESS | middy `onError` sets `request.response`, never rethrows |
| other errors log loudly, 500, no leak | reuse `genInternalServiceErrorMiddleware` — ⚠️ deliberate divergence, see F2 |
| the fixed-shape path still serves | ⚠️ **retracted by the wisher** — this is now a break |
| coverage proves the wire bytes | local harness + real `fetch` — **partially**, see F4 |

⚠️ **the `translate` namespace serves no row of this table.** it is in scope by wisher instruction
and is the largest part of the diff. treat the response work and the `translate` lift as two
deliverables that share a branch — and consider whether they should.

**the retracted line:** the wish asked that the fixed-shape path survive. the wisher retracted it —
the library is new, one contract beats two. the *convenient default* survives: `{ body: x }` still
yields 200 + json. this warrants a major bump.

### pros

- **one contract, one chain, one export.** no drift between peers is possible, because there is no
  peer. this deletes the shared-chain-builder refactor and two fulcrums outright.
- **the guardrails survive** — trail, io logs, normalization, introspection. the hand-roll lost
  every one.
- **the footgun closes at compile time.** `{}` is unrepresentable.
- **both wire shapes are nameable, and one never was.** `outputAfter` is the value this wish is
  about, and the sdk had no term for it — which is why it stayed hardcoded so long.
- **`schema` and `translate` line up point for point**, so a reader checks two namespaces against
  one diagram instead of a level-gap.

### cons

- **a break in three places** on `forApiGateway`, plus two config renames on `genLambdaEndpoint`.
- **a builder is now owed** (`asApiGatewayResponseSchema`) to keep the call site a one-liner.
- **the diff spans two deliverables** — one revert cannot scope to one of them.

### edgecases → pit of success

| edgecase | how the contract keeps you safe |
|---|---|
| handler returns `{}` | compile error — `PickAny` demands at least one key |
| handler omits `status` | 200, defaulted by the sdk before any middleware, so `??= 500` never applies |
| handler sets `Content-Type: text/xml` | serializer returns early; xml reaches the wire byte-identical |
| handler omits `body` on a 204 | the sdk OMITS `body` too, so `ApiGatewayResponsePayload` declares `body?: string`. `body: ''` is unsafe — the serializer `JSON.stringify`s it into `'""'` unless a `Content-Type` is already set, and a 204 must not carry one (probe → `appendix/verification.md`) |
| body present, `Content-Type` absent | serializer stamps `application/json` — a real default |
| a twilio body carries caller PII | `translate.log` defaults to metadata-only; body content never reaches cloudwatch unless opted in |
| handler returns a non-object | fail loud via `isApiGatewayResponse.assure(...)` |
| `{ introspect: 'schema' }` to a form webhook | never triggers — with `deserialize.body: false` the body stays a string, and the guard requires an object |
| a secret in an error message | the 500 never echoes `error.message` |
| a custom `payload.input` that drops the trail wrapper | cannot happen — the trail read runs first and is not replaceable |
| disarmed input + a parsed `schema.input` | fails loud at validation; zod names the field |
| a reader confuses absent with off | the two differ maximally in form — `undefined` vs `false` |
| a family omits one of the four shapes | compile error — TS2344 (verified by probe) |
| a custom `payload.output` that forgets to wrap the default | ⚠️ **not guarded** — see awkwardness #4 |
| two `Set-Cookie` headers / binary body | deferred — `PickAny` makes each an additive key later |

## what is awkward

1. **`asApiGatewayResponseSchema({ body: z.undefined() })` for a 204-only endpoint** is a mouthful.
   the wisher classes the choice beneath it as a pro; the builder is the ceremony the
   schema-names-a-point rule costs, and it lands on every call site.
2. **"verbatim" is aspirational once any middleware runs.** cors may add headers; introspection may
   short-circuit. the promise holds where claimed: *once the handler returns, its response is
   verbatim*.
3. **the break lands on a suite, not just consumers** — all 10 extant test cases change shape,
   which is the signal that the contract moved.
4. ⚠️ **`translate.payload.output` composes with a default a consumer must know to call.** a
   forgotten wrap ships an unencoded response with no compile error — a real
   `rule.require.safe-by-default` hazard. **study this one first.** a `{ before }` / `{ after }`
   compose affordance is the candidate fix, deferred because it changes every slot at once.
5. **the `invoke` input break serves no acceptance line.** right shape, kills an `as`-cast, but
   deferrable.
6. **`genLambdaEndpoint` binds `outputBefore` and `outputAfter` to the same type** — honestly, since
   a lambda invoke response **is** its payload. document it at the bind site, else it reads as a
   defect.
7. **the indexed accesses** (`TShapes['inputBefore']`) are noisier than positional parameters and
   give worse mismatch errors. accepted so the four terms are structurally bound.
8. **a new dependency for one type** — `type-fns` for `PickAny`.

☝️ **five of these form one family**, and it is worth a reviewer's note that all five were found on
this one stone: a claim sourced to a **vendor's type** (F30), to a **shared role** (F31), to a
**tool's silence** (r3), to a **signal never seen to fail** (r8 — eleven green snapshots that could
not go red for the defect in front of them), and to a **convergent find** (F32 — five reviewers on
one line, read as reassurance that the defect was singular). one defect, five disguises — and each
disguise fooled a self-review that had already passed on other dimensions.

the fifth is the most expensive, because its disguise is **agreement**. convergence proves a defect
was *visible*; it says not one word about whether it was *singular*. the four peers in that array
were unchanged context in every diff, so every reviewer read past them.

**four of these are counterweights** to a rule above them, and a rule applied without its
counterweight over-fires — measured four times on this stone:

| the rule | its counterweight | the pair says |
|---|---|---|
| `ungrounded-type-params` | `names-by-position-over-claim` | a name must trace **and** must not assert |

the fourth is the sharp one: `wet-over-dry` fired **correctly** on a slot with no evidenced
consumer, and the correct fire still cost a domain term. **prune a slot, never a name.** each pair
is now cross-linked bidirectionally with a `⚖️` marker that names what the left side alone approves.
