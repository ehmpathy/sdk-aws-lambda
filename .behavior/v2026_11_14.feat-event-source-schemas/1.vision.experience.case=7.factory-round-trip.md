# case=7 — the two halves of the event-source axis agree

care: critipath · feel: happy · inventory: c13

## .narrative

a tester builds an event with `asLambdaEvent.fromSns({ messages: [JSON.stringify(notice)] })` and runs
the handler. the event parses under `asLambdaEventSchema.fromSns({ payload })` with no override. one
source list, two directions (`define.lambda-event-source`): if a factory ever emits a field the schema
refuses, or the schema demands one the factory omits, a test goes red.

real aws sample events parse too, so neither half drifts from the wire. two grades of "real":

- **docs samples** — cheap, but they drift: the sns docs sample's cert-url key disagrees with the
  aws-lambda type (F10)
- **captured deliveries** — an echo lambda in the demo account (`provision/aws.infra/account=demo/`,
  `howto.provision-demo-infra`) subscribed to a real sns topic and kinesis stream, its received
  event committed verbatim as a fixture. this is the only grade that measures the wire, and it
  settles F10

the docs samples are the floor; a captured delivery is the target.

## .bdd sketch

```
given a tester whose sns handler is wired with asLambdaEventSchema.fromSns({ payload })
  when [t0] the tester builds an event via asLambdaEvent.fromSns and runs the handler on it
    then the tester sees invoke receive the decoded Message
given the same tester with an aws-documented sample sns event (verbatim)
  when [t1] the tester runs the handler on it
    then the tester sees it accepted, never refused at the envelope
given a tester whose kinesis handler is wired with asLambdaEventSchema.fromKinesis({ payload })
  when [t2] the tester builds an event via asLambdaEvent.fromKinesis and runs the handler on it
    then the tester sees invoke receive each data decoded from base64
given the same tester with an aws-documented sample kinesis event (verbatim)
  when [t3] the tester runs the handler on it
    then the tester sees it accepted
given the same tester with an sns event and a kinesis event captured from real demo-account deliveries (verbatim)
  when [t4] the tester runs each handler on its captured event
    then the tester sees each accepted
    then the captured sns event's cert-url key settles F10
```
