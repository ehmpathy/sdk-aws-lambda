# case=8 — kai migrates one handler, end to end (the dense walk)

care: critipath · feel: happy, with two sharp turns · inventory: c21 (walks c15, c1, c13, c5, c9, c14, c2, c20)

## .narrative

kai retires the rubber-stamp on `consumeSESEmailEventFromSNS` in one afternoon, and the walk crosses
every boundary this feature has.

1. kai swaps the schema to `asLambdaEventSchema.fromSns({ payload: schemaOfSesNotice })` and deletes
   the `JSON.parse` line. tsc passes: the handler still accepts `SNSEvent` as aws sends it.
2. kai's test builds the event with `asLambdaEvent.fromSns({ messages: [JSON.stringify(notice)] })`
   and runs the handler. it parses with no override; the handler reads a typed notice.
3. kai adds a second test with an aws sample sns event, envelope only. it parses — the contested
   cert-url key does not trip it.
4. a misrouted sqs event in a third test is refused at `Records.0.Sns`, before business logic.
5. kai deploys to prep. a peer service introspects the contract and sees the wire face:
   `Message: string`, never the decoded shape.
6. a week later ses sends `DeliveryDelay`. the schema refuses it; a warn line names the path; the
   invoke succeeds, so no retry loop and no dlq noise. kai widens the enum.
