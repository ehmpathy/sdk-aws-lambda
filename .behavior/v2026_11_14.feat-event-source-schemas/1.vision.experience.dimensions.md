# experience dimensions — event-source schemas

## .the axes

| axis | values |
|---|---|
| **R** actor | author (wires the handler, compile time) · runtime (aws delivers to the deployed handler) · tester (runs the handler on `asLambdaEvent.from$Source`) · reader (a peer or codegen introspects the contract) · wirer (an upstream tool emits the handler) |
| **S** source | `sns` · `kinesis` · `sqs` · other (`apiGateway`, `s3`) · absent (a direct-invoke schema with no source mark, c41) |
| **P** payload schema | absent (envelope only) · present, json (default) · present, text (`deserialize: { payload: false }`) |
| **D** message format the producer sends | json · text · binary (KPL aggregate, gzip, an s3 pointer's json counts as json of the wrong shape) |
| **A** arrival vs the declared schema | valid (a nullable field sent null, e.g. `Sns.Subject`, counts as valid, c39) · envelope malformed (wrong source, field absent) · message fails `payload` · aws adds an unknown key · a schema callback (`.refine` / `.transform`) throws (c34) |
| **N** records per invoke | 0 (kinesis only, c33) · 1 · many · many past the line cap (> 100 ids or > 20 issues, c35) |
| **F** fault after validation | none · handler throws caller fault · handler throws server fault · handler throws a non-`Error` value (c37) |
| **L** refusal trace | warn line at info level · debug only · no log in context (c38) |
| **Z** zod in the consumer's tree | the sdk's copy · a foreign copy or major · the sdk's copy, wrapped by the consumer (c36) · a source mark left by another copy of this package (c42) |
| **H** what the handler reads | the message · `MessageAttributes` · kinesis window fields |
| **W** the frame a call arrives in | ancient (the bare event, as aws sends it; every `R: runtime` call, c44) · contemp (the `{ event, trail }` wrapper `runLambdaEndpoint` frames by default; `R: tester` only, c45) |

## .the orthogonality notes

- **D vs P** — D is what the producer sends; P is what the author declared. "not decodable" is not an
  axis value: it is the cell where D and P disagree (D = text or binary under P = json; D = binary
  under P = text). this split replaces the earlier "inner not decodable" value of A, which mixed the
  two
- **L** exists because the same refusal (A = message fails `payload`) can leave a warn line or only a
  debug line. which one is a product choice (F9), and it decides whether the refusal is loud
- **Z** and **H** were one grab-bag axis before. Z varies independently of every other axis. H does
  not: it depends on S. `H = MessageAttributes` exists only under `S = sns`, and `H = window
  fields` only under `S = kinesis`. the crossed cells (`MessageAttributes × kinesis`,
  `window fields × sns`) are impossible by nature, verdicted as c31

## .the walked product

collapses, each with why:

- `N` is fixed to 1 for sns (one message per invoke, q5)
- `P = absent` makes `D` moot (naught is decoded) — except that `data` stays base64 for kinesis
- `F` exists only on rows where the schema passed (`A ∈ {valid, unknown key}`)
- `L` matters only on refusal rows; the vision fixes `L = warn` (F9), so the `debug only` value is a
  rejected design, verdicted once (c20)
- `S = sqs` and `S = other` collapse to one row each (F1; out of the wish)
- `Z`, `H`, and `R = wirer` each vary one value against the happy row; their outcomes do not compound
- `R = tester` and `R = reader` each walk the happy row per source
