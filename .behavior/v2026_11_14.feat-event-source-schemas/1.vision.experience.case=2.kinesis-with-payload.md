# case=2 — kinesis batch, each record decoded

care: critipath · feel: happy · inventory: c3

## .narrative

a clickstream lands in kinesis; a lambda aggregates it. each record's `data` is base64 of a json
string. the author never writes `Buffer.from(data, 'base64')` again: the schema decodes base64 → utf8
→ json, validates against `payload`, and hands each record over typed.

```ts
export const handler = genLambdaEndpoint.forAsk({
  schema: {
    input: asLambdaEventSchema.fromKinesis({ payload: schemaOfClick }),
    output: z.void(),
  },
  invoke: async ({ payload }, { log }) => {
    const clicks = payload.Records.map((record) => record.kinesis.data); // Click[]
    await setClickTallies({ clicks }, { log });
  },
});
```
