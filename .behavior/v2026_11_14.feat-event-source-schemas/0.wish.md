sdk-aws-lambda ships prebuilt zod schema generators for the common aws event sources (sns, sqs, kinesis), so an event-source lambda wired via genLambdaEndpoint gets a real, validated TInput instead of a hand-derived envelope or a `z.object({ Records: z.array(z.any()) })` rubber-stamp.

each generator validates the aws envelope, and optionally takes a schema for the inner message the handler decodes (`Records[].Sns.Message`, `Records[].body`, `Records[].kinesis.data`), so one call validates the whole payload the handler depends on.

names follow the repo's `as*` transformer convention. the shapes match the aws-lambda types (SNSEvent, SQSEvent, KinesisStreamEvent), so no `event as SNSEvent` cast is needed at the consumer.

done = the generators are exported, covered by tests against real aws sample events, and released.
