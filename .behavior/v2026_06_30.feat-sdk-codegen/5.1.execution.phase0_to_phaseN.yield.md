## execution decisions (divergences from blueprint, documented)

- **[decision] format mechanism** — the blueprint (nitpick 5) leaned "biome-format
  in-process via `@biomejs/biome` api." at execution the real programmatic api is
  `@biomejs/js-api@6` + a separate wasm backend, ESM-only — it complicates the
  CJS build and is a heavy runtime dep for a format nicety. **decision:** emit
  **biome-conformant text directly** from our own templates (we control the exact
  whitespace to match this repo's biome config) and verify conformance via a lint
  check on the generated output in the acceptance tests. this achieves the same
  goal (snapshot determinism + generated files pass the consumer's `biome check`)
  without the heavy dep. so `@biomejs/biome` stays a **devDep** (not promoted).
