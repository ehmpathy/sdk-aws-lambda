# 3.1.3 internal research — prod codepath patterns

> what production patterns exist in this repo, how they relate to the wish, and
> whether the codegen will [REUSE] / [EXTEND] / [REPLACE] each. test codepaths

## the shape of the wish, in one line

the codegen is a new **orchestrator + CLI** that calls the repo's *already-built*
contract-discovery spine, then emits three files. almost every dependency it has
is **[REUSE]**; it adds a thin new emit layer and a `bin`.

## P9 — build + package pipeline  [EXTEND]

**cite 13** — `package.json` (scripts)
> "\"build:compile\": \"tsc -p ./tsconfig.build.json && tsc-alias -p ./tsconfig.build.json\""

**cite 14** — `package.json`

relation: there is **no `bin` field** today (confirmed: package.json has `main`

`src/contract/cli/` entrypoint that compiles into `dist` via the extant
`build:compile`. no new build tool needed (tsc + tsc-alias already present).

## P10 — available deps for the emit layer  [REUSE]

**cite 15** — `package.json` (dependencies + devDependencies)
> "\"zod\": \"4.4.3\"" ... "\"domain-objects\": \"0.32.0\"" ...
> "\"helpful-errors\": \"1.7.3\""

relation: `zod@4.4.3` provides `z.toJSONSchema` (already used server-side) and,

F3) is `json-schema-to-typescript` for the type-emit — a **[EXTEND]** of the
dependency set, added via `set.package.install`.

## gaps flagged for the blueprint

- **[EXTEND-new] name→symbol transform** — `svc-jobs` → `svcJobs` (object/file) +
  `SvcJobs` (dobj prefix). no extant helper; must be a new transformer with a
  pinned rule (multi-hyphen: `svc-trust-safety` → `svcTrustSafety`).
- **[EXTEND-new] the emit layer** — three-file writer (barrel + mechanisms +
  resources) with the "generated — do not edit" banner (uc.1). new; no extant
  file-emit pattern in this repo (it's an sdk lib, not a codegen, today).
- **[EXTEND-new] pragma reader** — parse `x-domain-object` out of the introspected
  json-schema to recover name + primary/unique/alias/nested. new; pairs with the
  external-research recommendation to read the pragma directly (no zod tool).
