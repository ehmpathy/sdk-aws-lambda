# case=5 — the local locus labels an escaped throw as the cloud does

**cell**: L — error with inherited name, error with own name · sharp × criti
**seat**: the endpoint author, who trusts the local suite as the pr gate

from that seat: before, the suite was green, the pr merged, and prep went red on the same throw — the local run had lied about what the cloud would say. after, the local suite says what prep says, so a red shows up at the pr gate, where it is cheap.

## narrative

an author tests a raw handler (no `genLambdaEndpoint` chain) through `runLambdaEndpoint.onSerialized` at the local locus. it throws a helpful-errors 1.7.3 `ConstraintError`, whose `.name` is the inherited `'Error'`.

before: the local serializer read `constructor.name` and wrote `errorType: 'ConstraintError'`, so the caller saw a caller fault. the aws runtime reads `.name` and writes `'Error'`, so the cloud caller saw a server fault. the local gate passed; prep failed.

after: the local serializer reads `.name`, exactly as `toRapidResponse` does, and `typeof error` for a value that fails `_isError`. the local run shows `Error`, the same as the cloud. the author sees the truth at the pr gate, not in prep. an error whose `.name` was set — aws's own `CredentialsProviderError` — reads by that name on both loci.
