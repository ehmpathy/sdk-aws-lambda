# case=3 — the local run tells the truth about the wire

sharp × critipath. the clamp of wish done #1.

## narrative

kai runs his acceptance suite on the local locus before he opens a pr. he trusts that a green local run means a green prep run.

before: an error whose `.name` and class disagreed — a helpful-errors `ConstraintError` (`.name` = `Error`), or an aws `CredentialsProviderError` (class = `Error`) — was labelled by its class locally and by its `.name` on cloud. kai's suite went green; prep went red; he had no local way to reproduce it.

after: the local locus labels every throw by `.name`, exactly as the aws runtime does. if a class reaches the wire unnamed, kai sees `Error` locally — the same red prep would show — before he ever opens the pr. the fix it teaches: name the class (helpful-errors#45), or build the handler via `genLambdaEndpoint`, whose guard names it.
