# experience dimensions

## axes

| axis | values | why orthogonal |
|---|---|---|
| A. locus | local · cloud | where the throw is serialized; set by the caller's `at`, independent of what the handler throws |
| B. path of the throw | **B1 answered** — a genLambdaEndpoint middleware sets a response · **B2 rethrown** — a genLambdaEndpoint chain lets it escape to the runtime · **B3 raw** — no genLambdaEndpoint chain at all | the route a throw takes out of the handler. family and fate fold into this one axis, since fate is a function of family × fault kind (see the map below) — two axes would leave whole rows impossible |
| C. thrown value | **C1 unnamed** — an error, `.name === 'Error'`, class more specific (helpful-errors 1.7.3) · **C2 explicit** — an error whose `.name` was set by its class or thrower · **C3 plain** — a bare `Error` · **C4 non-error** — a thrown string / object with no `message` · **C5 frozen unnamed** — C1, but non-extensible | ⚠️ a folded product, declared rather than hidden: it is the cross of three latent axes — **value kind** (error · non-error), **name state** (unnamed · explicit · plain), **mutability** (extensible · frozen). the cross collapses to these five because a non-error has no name state, and mutability changes an outcome only for an unnamed error (the one case the guard writes). the five values are mutually exclusive over that collapsed cross |
| D. fault kind | **D1 caller** — ConstraintError / BadRequestError · **D2 caller subclass** — `class X extends ConstraintError` · **D3 server** — MalfunctionError or any other class | the class the value is declared as — not what the thrower meant: a thrower who means a caller fault but throws a bare `Error` is D3. what the caller actually concludes is an outcome of B × C × D and sits in the inventory's outcome column. C × D is correlated through the latent **class identity** (does the value have a class, and which): a C3 has class `Error`, so it is always D3; a C4 has no class, so D does not apply. both recorded as impossible, below |

## the B map — which family lands where

## actor — inert, and why

three actors meet this behavior: the endpoint author (runs the tests), the caller (reads `getParsedResponse`), the raw-handler author. all three observe one quantity — the `errorType` the caller classifies — so the actor does not change the outcome of any cell; it changes only who reads it. each case names its actor in the narrative instead of an axis.

## impossible / forbidden, with reasons

- **impossible (nature)** — C3 × D1/D2: a plain `Error` has no caller-fault class. C4 × D1/D2/D3: a non-error value has no class at all; recorded once as C4 × "n/a". B3 × answered: folded away by axis B.
- **forbidden (nurture)** — the ESCAPE in B1: `genConstraintErrorMiddleware` and the forApiGateway 500 builder answer instead. the escape is attemptable; the sdk rejects it. so B1 cells are the answers that occur — demoed or itemized, uniformly — and the forbidden escape is the reason each records.
- **locus collapse** — after the fix, the local serde answers the same `errorType` as `toRapidResponse` for every C (case=3, case=7). so every B2 / B3 cell's `errorType` verdict holds on both loci; A is walked once per cell as "local = cloud", proven by the serde clamps rather than repeated per row. B1 answers never reach the runtime's serializer, so A is inert there too. the collapse claims `errorType` only: the stack field is the one known divergence, itemized off-grid.
