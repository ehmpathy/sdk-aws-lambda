# case=4 — a raw handler's local test now tells the truth about prod

sharp × alterpath. B3 × C1 × D1.

## narrative

noa maintains an older service whose handlers predate `genLambdaEndpoint`. her acceptance suite hands each raw handler to `runLambdaEndpoint` on the local locus. one refuses bad input with a helpful-errors `ConstraintError`, and her test asserts a caller fault.

before: her suite was green. in prod the same refusal arrived as `errorType: 'Error'`, a server fault, and callers retried it. her green was a lie about prod, and not one test in her suite could tell her.

after: her local run shows `Error` too, and her assertion goes red — the same red prod would give. the failure is loud, at the cheapest moment, and it names its own fix: build the handler via `genLambdaEndpoint`, whose guard names the throw, or bump helpful-errors once #45 ships `.name`.

## bdd

```
given [case4] a raw handler that throws a helpful-errors ConstraintError
  when [t0] noa runs it on the local locus
    then errorType = 'Error' — identical to the cloud runtime
    then the caller concludes a server fault, as prod does
```
