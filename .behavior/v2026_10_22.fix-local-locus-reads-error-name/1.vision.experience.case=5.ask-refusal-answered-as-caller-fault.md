# case=5 — an answered refusal reaches the caller as a caller fault (forAsk and forApiGateway)

sharp × critipath. B1 × C1 × D1 — the wish's declared outcome on the two families that answer.

## narrative

leilani calls `getQuote` with a malformed quote id. behind it sits a forAsk handler; a browser form behind it also posts to `postQuote`, a forApiGateway handler. both throw a helpful-errors `ConstraintError('quote id malformed', { hint })`. leilani must read each as HER fault — fix the input, never retry.

the guard runs first and names the throw `ConstraintError`. then `genConstraintErrorMiddleware` answers:

- **forAsk** — the body itself: contemp `{ error: { class: 'ConstraintError', message } }`, or the ancient `BadRequestError` envelope for an ancient caller
- **forApiGateway** — a 400 with that same body, stringified

either way the invocation SUCCEEDS, so no cloudwatch error and no retry. leilani's caller hydrates a `ConstraintError` whose message carries the hint — fast, loud, and it teaches the fix. local and cloud agree, since the answer is a response and never meets the runtime's serializer.

this path already worked; the clamp proves the guard does not disturb it — the guard runs before the error builders and adds only a name they never need for class detection.
