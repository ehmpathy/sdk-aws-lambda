# case=7 — a non-error throw carries prod's label in a local test

sharp × alterpath. C4 — pulled in under scouts honor.

## narrative

keoni inherits a legacy handler that does `throw 'quota exceeded'`. he snapshots the wire payload of each failure in his local suite, so a reviewer can see what callers receive.

before: his snapshot said `errorType: 'Error'`. prod's payload said `'string'`. his reviewer approved a snapshot no caller would ever see.

after: his local run labels the throw `'string'`, with `errorMessage: 'quota exceeded'` — exactly prod's payload. his snapshot now shows the truth, and if he wants a real name on the wire, the snapshot makes the gap plain: throw an `Error`. either way the caller concludes a server fault; what changes is that the label keoni reviews is the label prod sends.

## bdd

```
given [case7] a handler that throws a value that is not error-like ('quota exceeded')
  when [t0] keoni runs it on the local locus
    then errorType = 'string' (red before: 'Error')
    then errorMessage = 'quota exceeded'
```
