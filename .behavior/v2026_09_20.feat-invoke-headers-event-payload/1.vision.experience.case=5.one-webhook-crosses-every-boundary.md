## the narrative

bruce runs a payments webhook. one handler, four jobs, and every one of them touches a different
edge of this change:

```ts
export const handler = forApiGateway({
  schema: { input: z.object({ amount: z.number() }), output: /* … */ },
  cors: { origins: '*' },
  invoke: async ({ headers, payload, event }) => {
    // 1. the provider signs each request
    if (!verify(headers['x-signature'], payload)) return { status: 403 };

    // 2. the ops dashboard wants to know which route answered
    log.info('charge', { method: event.httpMethod, path: event.path });

    // 3. the provider's replay tool needs the bytes exactly as sent
    await archive(event._.raw);

    return { body: { charged: payload.amount } };
  },
});
```

bruce's spa reads the response cross-origin. the provider migrates bruce's endpoint from a rest api
to an http api one tuesday — **and bruce changes not one line.**

that last sentence is the whole point of the walk. every spotlight case proves one read survives the
migration; **this one proves they survive it together**, which is a different claim.

## the bdd sketch

```

  and   the handler holds no version-specific code

  when  [t0] a v1 request arrives, POST /charge, signed
  then  `headers['x-signature']` is the signature            # boundary 1 — the header read
  and   `event.httpMethod` is 'POST', `event.path` is '/charge'   # boundary 2 — the envelope
  and   `event._.raw.httpMethod` is ALSO 'POST'              # boundary 5 — the escape hatch
  and   `payload.amount` is the validated number             # boundary 6 — the body
  ⇒ on v1 the reconciled shape and the raw shape AGREE, so this arm alone
    cannot tell them apart. that is why [t1] exists

  when  [t1] the identical request arrives as a v2 wire form
  then  `headers['x-signature']` is UNCHANGED
  and   `event.httpMethod` is STILL 'POST'
  and   `event._.raw.httpMethod` is `undefined`              # boundary 3 — the reconcile
  and   `event._.raw.requestContext.http.method` is 'POST'
  and   `payload.amount` is UNCHANGED

    nowhere else. a build that bound `event` to the raw union would pass

  when  [t2] either response leaves the chain
  then  `access-control-allow-origin` is present             # boundary 4 — the vendor seam
  ⇒ proves the header lift did not starve `@middy/http-cors`, on BOTH versions.

  when  [t3] the handler is re-read for version-specific code
  then  there is none
  ⇒ the C-axis invariance, PROVEN by one artifact rather than asserted

```

## 🔴 the defect only this walk can catch

each spotlight reads **one** source. this walk reads **four** — `headers`, `payload`, `event`, and
`event._.raw` — in one handler, on both versions. so it is the only case that can observe them
disagree.

| a plausible mis-wire | caught by a spotlight? | caught by `[t1]`? |
|---|---|---|
| `event` bound to `_.raw` instead of the reconciled shape | ⚠️ **no on v1** — v1's raw carries `httpMethod` at the top level, so `case=2`'s v1 arm passes | ✅ `event.httpMethod` is `undefined` |
| `headers` lifted off `_.raw` rather than off the reconciled shape | ⚠️ **no** — `case=1` reads only `headers`, so it has no second source to disagree with | ✅ `[t0]`/`[t1]` read both |
| the cors seam starved **only** on the v2 arm | ⚠️ **no** — `case=4` runs one version | ✅ `[t2]` runs both |
| 🔴 `payload` bound to the envelope, or `event` bound to the body — **the two transposed** | ⚠️ **partly** — `case=1` reads only `payload`, `case=2` only `event`; each passes against a wrong bind if the other half is never read | ✅ `[t0]` reads **both**, so a transposition makes `payload.amount` and `event.httpMethod` fail together |

⇒ 🔴 **the fourth row is new with the ruled shape, and it is the sharpest.** `payload` and `event`
are the two fields this change **renames into each other's former senses** — so a bind that
transposes them is the one mis-wire that is plausible *because* of the rename rather than in spite
of it. only a handler that reads both in one body can observe the transposition.

⇒ **three interaction defects, invisible to every focused case, visible to this one.** that is the
value the density metric measures, and it is why the walk earns the richest demo despite its
alterpath care.
